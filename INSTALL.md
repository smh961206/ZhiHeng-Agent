# Install into ZhiHeng-Agent

Recommended:

1. Back up / commit the current repository.
2. Copy the contents of this package into the repository root.
3. Do not overwrite an existing `AGENTS.md` blindly; merge any valid existing instructions.
4. Start Codex with `START_HERE.md`.
5. Execute H0 only.
6. After H0 acceptance, set `docs/releases/CURRENT` to `V4.8` (H0 prompt instructs Codex to do this only after acceptance).
7. Implement releases sequentially.

This package intentionally contains FUTURE contracts and releases so Codex knows the destination, but `CURRENT` prevents future work from being implemented early.
