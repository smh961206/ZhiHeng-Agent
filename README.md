# 知衡 · 价值投资研究 Agent

React + Node.js。将V4.1 CORE/FULL转为六类研究任务、证据检索、估值工具和模型审计。只使用自动抓取的数据，不预置研究结果。

## 启动

Linux Docker 一键部署、代码更新、数据库版本迁移与备份回滚见 [部署文档](DEPLOY.md)。配置 `.env.production` 后执行 `bash deploy.sh up`，后续执行 `bash deploy.sh upgrade`。

要求 Node.js **22.13+**、pnpm、已启动的 Docker Desktop（Linux 容器）。

```powershell
pnpm install
Copy-Item .env.example .env
pnpm db:up
# 在.env配置模型后运行
pnpm dev
```

开发页面 `http://127.0.0.1:5173`，后端 `http://127.0.0.1:3001`。

```powershell
pnpm build
pnpm start
```

构建后统一使用 `http://127.0.0.1:3001`。Windows也可运行 `./start.ps1`，优先系统Node，找不到时使用本机已有Codex Node运行时。本应用仅监听本机，无多用户鉴权，不应直接暴露到公网。

必须填写 `LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`。模型需支持Chat Completions工具调用及按协议返回JSON。密钥只在后端读取；问题、组合信息、选用的历史研究快照和相关财报片段会发送给配置的模型服务。未配置模型直接报错。可设置 `SEC_USER_AGENT=应用名 真实联系邮箱` 以符合SEC来源访问要求。

## 使用与数据源

填写研究问题，添加最多3个证券代码（A股6位、港股1～5位、美股Ticker）。“查看行情”预览快照；“开始研究”按任务、配置和权限获取行情、结构化财务、官方披露及股东回报等资料，必要时按缺口补充网页正文。任务支持取消、执行轨迹、历史搜索、重载输入和Markdown导出。

| 市场 | 行情 | 官方披露 | 数据商补充（按配置、权限与任务） |
|---|---|---|---|
| A股 | 长桥优先（适配且配置后），东方财富、腾讯备用 | 巨潮定期报告及分红、回购、注销公告原文 | Tushare三张财务表、分红、回购、股本与历史估值 |
| 港股 | 长桥优先（配置后），东方财富、腾讯备用 | 港交所与巨潮独立目录、同报告期替代原件、分派及股本公告 | Tushare三张财务表；长桥基本面的分红、回购、公司行动与历史估值 |
| 美股 | 长桥优先（配置后），Yahoo Finance、腾讯备用 | SEC申报正文、官方XBRL核心事实及选定临时披露的实际链接附件 | Tushare三张财务表；长桥基本面的分红、回购、公司行动与历史估值 |

网页补充在启用并配置搜索后执行：先检索已有资料，再由 Tavily、Brave 定位原始网页，读取正文后纳入证据，搜索摘要不作为研究证据。数据商资料与官方原件分别标注，接入成功不等于每次取得全部资料。工作台、首页、手册及采集阶段的展示文案共用 `shared/research-data-copy.mjs`，具体使用来源和缺口以本次研究记录为准。

行情是**最新可得快照，可能延迟**，不是交易所逐笔直连。行情时间与抓取时间分开记录，休市显示最近交易行情。行情币种与财报币种分别验证，不默认港股财报为HKD。未核实口径的行情PE不自动用于估值。

财报历史范围3/5/8年；初筛按需缩减，其余模式按年度窗口和最近八个报告期选择，股东回报默认八年。年度缺口不再用更老年报填补。港股并用港交所和巨潮目录并保留相同报告期的下载替代；SEC最多补充8个历史目录，并读取正文、近期8-K/6-K及其实际链接的附件。分页、正文与采集预算的缺口分别记录。

PDF单文件32MB、解析180秒、最多600页/150万字符。PDF.js使用随依赖安装的CMap、标准字体和WASM文件，避免部分中文财报漏掉项目名称。逐页保存提取方式、文字质量、页码和行列位置；坏页不丢弃其他已读页，超时返回有足够正文的已读部分和未读范围。空白、稀疏、乱码或仅数字页会尝试本地OCR，每份文件最多4页、累计90秒，单页最多45秒；识别未完成或预算用尽保留缺口。中英文字库随固定依赖部署，运行时不从CDN下载，也不发送原件给外部OCR服务。OCR识别置信度不是财务准确率，数字仍待原件核对，不能单独作为计算依据。

已解析原文按证券、URL及解析版本持久归档最长10年，保留抓取时间、原件SHA256、文本及结构化证据完整性校验；读取归档不会重置原抓取时间。解析版本升级会重新读取原件，失败时可回退已校验旧文本并明确标记旧版限制。目录独立刷新以发现新披露与修订。缓存保留提取内容而非原PDF二进制。界面仅预览前12000字符，模型按页和表格检索，命中返回来源ID、块编号、页码、表头上下文及识别限制。

请求遇到连接重置、超时、HTTP 408/500/502/503/504 时进行退避重试，通常最多3次；行情每个来源最多2次、总计最多11秒，失败后切换独立备用源。403不重试并冷却15分钟；429不立即重试，至少冷却60秒并尊重 `Retry-After`。SEC请求统一节流，同属SEC的域名共享限流冷却；不通过切换SEC域名绕过拒绝访问。

行情、目录和SEC数据的相同请求并发复用，单个页面取消不影响其他仍在等待的请求；全部调用者取消时停止共享请求。内存缓存有容量上限：行情15秒、证券目录24小时、SEC公司查询1小时、SEC披露和XBRL响应5分钟、选定财报目录1分钟。行情各来源都失败时，仅允许使用15分钟内成功获取并保存在内存或数据库的快照，并在界面与研究来源中明确标为旧快照，保留原行情时间和抓取时间。财报分页或SEC历史目录失败会保留已找到的可读报告，同时记录缺口；不将缺失事实填为零。

SEC备用公司目录与Submissions接口分别按[SEC访问说明](https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data)和[官方API说明](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)实现；获取财务数据前再次核对Ticker及CIK。请在 `SEC_USER_AGENT` 填入应用名与真实联系邮箱。

联网诊断：`node --env-file-if-exists=.env scripts/data-diagnostics.mjs`。它检查三市场主/备用行情、巨潮最新PDF正文、SEC官方XBRL与备用公司目录，不调用模型或创建研究任务；成功读取的行情可保存到本地归档。诊断结果只代表当次连接状态。

美股分别读取官方申报正文与XBRL核心财务数据。年度和季度申报覆盖10-K、10-Q、20-F、40-F及修订，另外选取近期8-K/6-K及其结果附件。HTML保留表头、表格行及跨行跨列标记；内嵌XBRL补充CompanyFacts，按原始contextRef/unitRef核对实体CIK、实际起止日、维度、币种、scale和sign，不以财年标签代替实际期间，不重复乘展示倍数。最多读取20000个数值标签；已支持常见小数/千位转换、嵌套数值标签，nil、未知转换、跨文档引用和异常数值不作为有效事实。自定义概念保留原标签且不自动映射到核心指标；分部维度与合并口径分开。同期间修订保留历史，同日冲突不自动选值，不自动拼接TTM。核心字段覆盖检查的“observed”只表示看到标准标签，不是财务审计，缺标签也不代表公司没有披露。来源页提供官方申报原件链接。

来源403/429、接口变化、抓取或解析失败均明确报错，不绕过限制、不编造数据。任一标的完全没有可读官方财报时停止模型研究；部分失败保留缺口。公开接口没有服务可用性保证，长期生产使用应接入授权数据商。

### 可选接入：长桥行情、基本面与 Tushare 财务数据

在本地 `.env` 或部署用 `.env.production` 中补充以下变量。凭证只在服务端读取，不放入 `VITE_` 变量、不发送给模型或前端。未配置时继续使用现有公开来源。

```dotenv
TUSHARE_TOKEN=
LONGBRIDGE_APP_KEY=
LONGBRIDGE_APP_SECRET=
LONGBRIDGE_ACCESS_TOKEN=
```

- 长桥三项齐全后优先提供沪深 A 股、港股、美股行情，北交所继续走现有来源。接入官方 `longbridge` Node SDK 4.5.0，行情使用 `QuoteContext`，港美股基本面使用 `FundamentalContext`，不使用账户或交易接口。行情币种取证券基础信息；保留来源时间，不混入盘前、盘后、夜盘字段。连接在独立子进程中运行，行情10秒、基本面30秒超时；全部等待者取消时释放连接，原生SDK退出不会影响主服务。权限取决于账户实际开通情况。配置参考[官方 SDK](https://github.com/longbridge/openapi/tree/main/nodejs)。
- Tushare Token 配置后，按股票和年份查询三市场的利润表、资产负债表、现金流量表，经 HTTPS JSON 接口获取，结果缓存5分钟。原字段、报告类型、空值及修订记录保留，接口权限失败不阻止其他表与官方采集。港股、美股接口的币种和金额单位未明确返回时保持未知，需从官方原文核对；报告期不标成披露日，不将这些数据当作可直接用于时点回测的数据。来源明确标注“结构化财务（数据商）”，链接指向数据接口说明，不伪装为财报原件，也不计入官方财报成功读取数。参考[Tushare HTTP 接入](https://tushare.pro/document/1?doc_id=130)、[A股财务](https://tushare.pro/document/2?doc_id=33)、[港股财务](https://tushare.pro/document/2?doc_id=389)、[美股财务](https://tushare.pro/document/2?doc_id=394)。

配置后重启服务，再运行下列只读验证。它直接检查长桥与 Tushare，不会以公开备用源的成功代替新数据源验证，也不会调用模型、写研究记录或下单。

```powershell
node --env-file-if-exists=.env scripts/data-provider-diagnostics.mjs
```

检查贵州茅台、腾讯控股、苹果的报价及三张财务表；退出码 `0` 为全部通过，`1` 为至少一项失败，`2` 为凭证未配置而跳过。未配置时只能完成模拟与本地 SDK 加载验证，无法验证账户权限、真实延迟和财务口径。

### 股东回报与数据口径

配置 Tushare 后，A 股额外采集[分红送转](https://tushare.pro/document/2?doc_id=103)、[回购公告进度](https://tushare.pro/document/2?doc_id=124)和[每日股本](https://tushare.pro/document/2?doc_id=32)。这些接口与三张财务表共用请求间隔（600毫秒）、5分钟缓存和权限错误冷却。财务表多取一个年度，用于首年平均权益的期初值；模式 F 检查最近八个完整年度，并保留当年新增记录。

- 分红保留全部状态及日期，分别列出预案、实施记录和已到派息日的记录；检测同一事件的冲突数值。无记录不等于零分红，特别分红仍需官方原文辨别，不直接生成可持续DPS或支付率。
- 回购使用文档支持的日期参数查询全市场，再严格匹配证券。满2000行时拆分日期重取，每标的最多128次、120秒，达到上限保留已取得记录并标注未完成日期段；多次公告的同一原始记录去重，但不合并累计执行金额。回购用途、方案ID及实际注销证明未提供时保持未知，不推断为注销式回购。
- 股本保留每日原始记录及年度末次观测值，万股明确乘10000转为股；展示首次观察到的变动，变动原因保持未知。长桥三市场报价同时带证券基础信息中的总股数、流通股数和港股股数；静态信息没有生效日期时不拿抓取日期替代，也不视为稀释加权平均股本。
- 每个标的生成“数据覆盖与口径检查”，检查财务年度、期初权益、资产负债数值一致性、分红历史及股本来源。`observed`只表示观察到资料，不表示已经与原文核验。检查记录不能单独作为估值证据；数据商财务/股东回报数据参与计算时须同时关联已读取官方披露，跨证券和已知币种冲突会被阻止。
- 港美股已补接长桥 `valuationHistory`、`dividendDetail`、`buyback` 和 `corpAction`。保留实际返回窗口、采样间隔、日期和空值，不能把少量周/月采样说成完整五年每日历史；分红描述也不能直接作为普通现金股息，须辨别特别/实物分派并核对官方原文。

只读八年验证（默认贵州茅台，可传入另一个 A 股代码）：

```powershell
node --env-file-if-exists=.env scripts/shareholder-data-diagnostics.mjs 600519
```

退出码 `0` 表示查询完成且无请求失败或已知截断，不表示所有业务资料完备或财务审计通过；`1` 为请求失败或范围不完整，`2` 为未配置凭证。脚本不调用模型或交易、不写研究任务；成功读取的数据可写入本地归档。

## 数据完整性与连续可用性

- A股 `daily_basic` 读取历史PE/PE-TTM、PB、PS/PS-TTM及股息率，确定性计算三年、五年经验分位；空值、无效比率和历史不足均明示。港美股采用长桥实际返回的估值采样点，保留缺少指标和历史长度，不混用采样频率。
- 官方原件读取使用严格域名与路径允许列表。港股下载失败可尝试同公司、同报告期的已发现替代原件；财报和目录在MongoDB归档，读取时校验文本哈希。归档失效或写入失败不阻断本次正常外部读取，但会报告缓存故障。
- 官方目录刷新失败可回用30天内目录，明确标为旧目录；行情回用上限15分钟；Tushare/长桥基本面故障可回用30天内记录，估值数据回用上限2天。权限拒绝不伪装为成功；来源时间与抓取时间不重新标新。凭据仅参与不可逆账户范围键，不写入资料正文。
- 股东回报补充巨潮分红/实施/回购/注销公告、港交所分派与证券月报（按历史窗口）和最近90天翌日披露；按年度与实施相关标题选择最多24份专项原件。SEC临时披露选最近8份，各最多3份已链接的结果附件。达到预算如实保留未读范围。
- 分红实施记录按事件日期去重，冲突不猜测；回购原文线索按来源ID与页码定位，关键词命中不证明实际注销。XBRL保留真实起止日、单位和修订，不重复乘千/百万、不混加单季与累计。
- 外部数据商或官方站点均不能保证绝对无故障。本实现提高故障时的连续可用性，并在无有效来源时保留缺失；它不提供100%可用性的合同SLA，也不将过期或未核验数据用于宣称当前精确估值。

完整采集验收（不运行模型或交易，会保存本地数据归档）：

```powershell
node --env-file-if-exists=.env scripts/data-readiness-diagnostics.mjs
```

结果保存为 `artifacts/data-readiness.json`。三个示例的实测通过不代表全市场、全部特殊行业、公司行动或口径均已完备。

随后运行 `node --env-file-if-exists=.env scripts/data-failover-diagnostics.mjs` 可检查数据库归档在新客户端实例中的恢复：注入连接故障，不中断真实服务；验证旧资料保留时间、故障标签及行情15分钟有效上限。它会刷新一次真实行情，读取上一步产生的基本面和官方资料归档，不调用模型或交易。

## 主动网页补充

核心行情、结构化财务和官方报告仍走固定采集接口。研究模型可按具体缺口补充行业统计、公司材料、政策与最新事件原文，后端执行以下顺序：

1. `search_evidence` 检索本次资料库，返回检索编号和真实命中段落。零命中返回空结果，不再用无关段落填充。
2. `search_web` 必须引用该次检索编号并说明尚缺什么。后端重新检查已有资料，再复用同一公开关键词搜索；资料库更新时先要求重新审阅。搜索服务只提供候选链接和定位标题，摘要、自动生成答案和搜索服务给出的日期不会进入证据正文。
3. 直接读取候选原页或PDF，提取正文、原文发布日期、资料期间线索、发布域名、抓取时间和哈希。日期不明或多期间无法对应时保留未知/待核对，不以抓取日期代替。只有成功读取的正文分配新的来源编号。
4. 模型按来源编号检索补充正文；`resolve_web_gap` 要求给出真实连续摘录及其对应理由。程序验证摘录存在，语义判断仍由模型负责。身份、日期、截断和旧资料的限制不会因找到一句话而消失；尚未解决的缺口必须进入最终审计的缺失清单，数据等级标为受限。

本地 `.env` 或部署 `.env.production` 配置如下。Tavily 优先，Brave 为可选独立备用，不需要两家都配置：

```dotenv
WEB_SEARCH_ENABLED=true
TAVILY_API_KEY=
BRAVE_SEARCH_API_KEY=
WEB_RESEARCH_ISSUER_DOMAINS={}
```

密钥仅在后端读取；搜索请求只发送模型提出的公开关键词，不自动发送整个问题、持仓或先前研究。关键词检查拒绝链接、邮箱和本地密钥，模型规则进一步禁止外发私人上下文。搜索语义由模型决定，关键词过滤不等于所有个人信息已被自动识别。未配置或关闭搜索时，固定接口继续工作，网页缺口保持未解决。

`WEB_RESEARCH_ISSUER_DOMAINS` 是操作人员确认的证券与公司官网域名映射，例如 `{"US:AAPL":["apple.com"],"HK:00700":["tencent.com"]}`。内置识别部分监管、统计和交易所域名；搜索排名和模型声称不能自动赋予其他网站“官方”身份。未确认发布者的已读网页可作为待核查补充资料；计算工具拒绝未读正文、身份未知、发布日期未知及搜索摘要，并要求补充财务数字同时关联固定采集得到的官方披露。

每项研究最多6次搜索、8次正文读取，每个缺口最多尝试3个候选，累计联网时间180秒；启用搜索时最多18轮模型工具交互。网页单文件最多12MB，HTML/纯文本最多50万字符，PDF沿用上述解析及本地OCR预算。不执行网页脚本，不越过登录、验证码、403和限流。仅连接通过DNS校验的公开HTTPS地址，并在每次重定向后重新校验及固定解析地址；SEC正文沿用固定采集器的访问限制。若桌面网络返回198.18/15保留地址，会向Cloudflare公共DNS核对该公开域名，再连接校验后的公网地址；可用 `WEB_RESEARCH_PUBLIC_DNS=false` 关闭该兼容处理，不会直接放行保留地址。

已读网页文本和对应链接目录归档30天；正文6小时内可直接复用，超过后尝试刷新，刷新失败明确标记旧资料并保留原时间。搜索失败可复用同一公开查询下的已读原文链接，但继续保留“未确认新披露”的缺口。缓存存文本与哈希，不是原PDF二进制备份。来源界面展示“网页原文（补充）”、原文日期、期间与限制。归档不保证长期站点可用，也不证明网页中的事实正确。

配置后重启服务，执行 `node --env-file-if-exists=.env scripts/web-research-diagnostics.mjs` 验证搜索、原始正文及归档恢复。脚本不调用模型或交易，会写入公开资料归档；未配置凭证时仅测试已知原始链接，退出码2，不能当作真实搜索验收。结果在 `artifacts/web-research-diagnostics.json`。参考 [Tavily Search](https://docs.tavily.com/documentation/api-reference/endpoint/search)、[Brave Web Search](https://api-dashboard.search.brave.com/api-reference/web/search/get)。

## 架构

- `src/main.jsx`、`DataConnect.jsx`：工作台、三市场证券输入、行情、报告和历史。
- `server/market-data.mjs`：三市场行情备用源、代码匹配、财报抓取与覆盖记录。
- `server/market-request.mjs`、`market-cache.mjs`、`sec-directory.mjs`：来源白名单、重试/限流冷却、共享请求与缓存、SEC公司查询备用目录。
- `server/pdf-worker.mjs`：独立线程提取PDF，支持超时和取消。
- `server/agent.mjs`：默认10轮、启用网页搜索时18轮工具调用上限、证据检索、FULL规则检索、模型审计、来源ID检查。
- `server/web-research.mjs`、`web-search-provider.mjs`、`web-evidence.mjs`、`web-evidence-request.mjs`：本地检索先行的缺口流程、搜索服务、原始正文及元数据、归档和公开网络读取约束。
- `server/calculations.mjs`：市赚率三公式、N修正、价格锚/ROE敏感性、FCFF/FCFE DCF、收益率锚。
- `server/index.mjs`：HTTP、任务管理、取消和静态资源。
- `server/storage.mjs`：MongoDB 任务索引、GridFS 完整任务内容、财报/数据归档及按类别配置的过期索引。
- `knowledge/`：用户原始CORE/FULL副本；`data/`：旧版 JSON 数据，只用于迁移，保留原文件。

## MongoDB 持久化

`compose.yaml` 部署官方 `mongo:8.0`，仅映射 `127.0.0.1:27017`，使用 Docker 命名卷 `zhiheng-agent_mongodb_data` 和 `zhiheng-agent_mongodb_config`，自动重启策略为 `unless-stopped`。本地开发不设数据库认证，请勿将端口暴露到公网。

默认连接 `mongodb://127.0.0.1:27017`，数据库 `zhiheng_agent`；可通过 `.env` 中的 `MONGODB_URI`、`MONGODB_DATABASE` 修改。数据库不可用时后端启动失败，不回退到文件存储。`GET /api/health` 检查实时数据库连接。

后端每次启动会导入 `data/*.json` 研究任务和 `data/cache/*.json` 未过期缓存。已有任务不会覆盖，旧文件不会删除；损坏文件会明确报错并阻止启动，修复后可重试。也可独立执行 `pnpm db:migrate`。请只运行一个后端实例；重启时将遗留的排队/运行任务标记为中断失败。

任务摘要保存在 `jobs`，完整任务保存在 `job_payloads.files/chunks`，支持超过16MB的研究资料；历史内容版本保留以保障并发读取。财报正文保存在 `report_cache`，读取立即过滤过期数据，TTL 索引异步清理。只有正在运行或保存失败的任务保留在内存供界面查看。

`pnpm db:stop` 停止数据库，`pnpm db:up` 恢复。普通容器重建保留数据；不要执行 `docker compose down -v`，该命令会删除持久化卷。备份可使用容器中的 `mongodump`，恢复使用 `mongorestore`。

`pnpm test:mongodb` 在随机命名的临时数据库验证大文本、重连持久化、任务恢复、缓存过期和幂等迁移，结束后清理测试数据库。实现参考 [MongoDB GridFS 文档](https://www.mongodb.com/docs/drivers/node/current/crud/gridfs/) 和 [MongoDB 官方镜像](https://hub.docker.com/_/mongo)。

业务适配和大部分研究审计仍由模型执行。数值工具不认证事实，官方采集不代表全部假设已核实。跨币种、正常化、历史覆盖、市赚率行业适配仍需复核；没有完整组合上下文不得输出具体权重。

## 实时研究报告

`GET /api/jobs/:id/stream` 使用 SSE 推送当前快照、执行事件和报告增量，断线后浏览器自动重连并重新读取当前快照。离开页面不会取消任务。模型请求启用 `stream: true`，兼容工具参数分片；如果供应商仍返回完整 JSON，也可读取，但无法提供逐字输出。

生成中的内容仅作为未审计预览，审计通过后替换为正式报告；失败或取消时移除预览，导出仅对正式结果开放。执行轨迹按最新在前展示。反向代理需关闭 SSE 缓冲并允许长连接（例如 Nginx `proxy_buffering off; proxy_read_timeout 3600s;`）；服务发送15秒心跳。

草稿阶段只要求可阅读的 Markdown，JSON 交付协议仅用于独立审计阶段。前后端共用预览格式处理：去除包裹整篇报告的 Markdown 代码围栏，完整结构化草稿只提取报告章节，未完成或无法识别的结构化内容显示整理进度，不直接展示内部字段。前端同时兼容旧任务快照中的原始草稿。该处理只影响预览，原始草稿仍提交审计，正式报告仍须通过原有交付校验。

当前单实例以内存广播实时消息、MongoDB持久化任务和财报缓存，无需 Redis。若后续引入多个后端实例、独立任务进程或可靠任务队列，再设计共享任务状态和消息分发；普通 Redis Pub/Sub 不持久化断线消息，可靠重放可评估 Redis Streams。

## 页面路由与研究框架

平台使用 React Router 的浏览器路由：`/` 为首页，`/workbench` 为工作台，`/history` 为研究记录，`/handbook` 为研究手册，`/research/:jobId` 为研究详情；旧地址 `/framework` 保留查询参数与锚点并跳转首页。详情标签页使用 `?tab=audit` 或 `?tab=sources`；记录的关键词、状态、排序、页码保存在查询参数中。部署服务器需将非 API 的页面地址回退到 `dist/index.html`，本项目 Node 服务已支持。

首页集中展示上手指引、研究场景、服务方案、研究流程与原则摘要；六维评分和判断边界移至研究手册，避免首页重复展示详细标准。侧栏直接列出首页、研究工作台、研究记录与研究手册。研究手册的研究纪律页包含阅读标准、`knowledge/FULL.md` 第17节的30条禁止事项与第18节最终原则；`/handbook?tab=glossary` 的19个术语默认收起，点击名称或使用键盘展开定义、通俗解释、示例与适用边界，可同时展开多项对照。公式计算及高股息说明归入对应条目。手册章节保存在地址中，支持直接访问、刷新和浏览器返回；术语分类手动切换，窄屏完整展示三个分类。原文变更时，同步维护 `src/config/research-reference.js` 与相关展示文案。

失败或已取消的研究可在详情页直接“重试研究”。`POST /api/jobs/:id/retry` 接收 `expectedRetryCount`（首次为0），从服务端保存的输入重新执行当前记录，保持研究ID、创建时间和详情地址不变，不增加研究记录。原问题、已确定的模式、深度、标的、年份、组合信息及已保存的历史对照快照沿用；旧错误、结果、行情、来源、草稿和阶段状态重置为本轮内容，并记录重试次数与最近重试时间。前端保持当前标签页并重新连接进度；桌面和移动端共用提交锁。服务端通过运行锁、容量预留和数据库条件更新防止并发重启、过期请求与已删除记录被恢复。写入失败时保留原状态，允许再次尝试。提交期间离开页面不会被强制跳回。已完成报告的“复用研究输入”仍只载入工作台，不自动提交。

研究框架页围绕公司质量、证据链、估值假设和证伪跟踪说明价值；六类场景可切换查看交付内容并进入工作台，五个流程步骤支持点击与键盘切换。两组标签默认从各自第一个标签开始，每4秒自动轮播，不显示独立控制按钮；悬停、聚焦内容、离开可见区域或切到后台时暂停，恢复后重新计时。遵循系统“减少动态效果”偏好，启用该偏好时仅手动切换标签。两组内容在切换时保持高度稳定，窄屏只横向移动标签栏以显示当前标签。评分区域只展示规则权重，不预置公司分数。页面与新增交互复用 shadcn/ui，支持320px手机及桌面。各页面底部重复的品牌文案已移除。

`knowledge/CORE.md` 与 `knowledge/FULL.md` 是业务依据。`shared/research-framework.mjs` 是其可执行映射，统一六类任务、必要辅助模块、五个阶段、六维评分和输出协议。`server/knowledge.mjs` 在启动时检查Skill版本与绑定章节；原文版本、日期与SHA256随计划和最终报告保存。规则检索返回完整小节、来源与行号，超出窗口会标记截断。修改Skill时需同步映射与验证，不能只修改宣传页面。

`POST /api/research/plan` 与任务创建共用输入校验、模式路由和历史对照检查，不调用模型。创建时重新生成并保存计划；A 快速筛选强制Quick及五年范围，F 股东回报使用八年检索范围；长期价值研究中的分红问题保留B主模式并增加必要辅助模块。实际读取范围仍受来源覆盖限制，当前不自动展开指数成分或批量筛选全市场。

MODE A 交付协议为版本3：报告分为商业模式、五年趋势、最新一期与单季变化、资产负债表、财务红旗与反证、现金流与资本开支、估值与市赚率适用性、三个优势、三个风险、下一步验证十个章节。资料不足也须保留该章节及缺口。默认选择五个年度的官方年报和三个近期报告期；不为快筛额外拉取多年股东回报、估值分位或公司行动历史。核心行情及财报继续通过固定接口，网页仅按已有资料的缺口补充。

`calculate_screen_metrics` 校验显式金额单位、行业、ROE定义、实际起止期间和逐行来源编号，运算覆盖增长、Quick FCF、累计流量推导单季、历史ROE均值/中位数/总体标准差及余额比较。缺失不补零，基数非正不算增长率，重复或重叠年度先处理修订，直接单季与推导单季冲突保留。银行、保险等金融企业不计算工业企业现金流代理。工具不独立核实输入事实；历史ROE统计不等于正常化ROE。MODE A 在工具定义和执行入口均禁止完整DCF及股息估值工具。

研究思路页先显示公开的问题与验证计划，完成后显示3至8项关联实际来源的证据判断摘要。两个规则文件的版本和指纹可展开查看。导出按“研究计划与证据判断 → 实际工具调用与资料获取 → 完整结果、审计与来源”编排，保留实际参数、返回、失败及时间。旧报告缺少这些信息时明确未记录，不补造。摘要属于可复查的研究说明，不是隐藏思维链；程序仅检查结构和来源编号，不能代替事实核验。

工作台对 MODE A 显示固定筛选范围及三个研究动作，不呈现可修改的深度/年限选择框；问题自动匹配快筛时也使用同一交互。按钮为“开始快速筛选”，请求按 Quick 与五年范围提交。用户可以填写筛选关注点、展开本次查证问题，切换研究路径时保留已有输入。详情页区分读取资料、查证、计算、复核与未完成状态，并解释“报告已完成”及尚待核实事项。结论为“深度研究”的快筛可通过“准备深度研究”将同一标的与主要待验证事项带入新的工作台输入；此操作不创建任务，提交后才运行。财报更新入口继续用于对照旧判断。

计划与创建API均新增可选字段：`previousResearch`（上次结论，最多30000字）、`baselineJobId`（已完成的同标的研究）、`portfolioContext`（`holdings`、`weights`、`assetRange`、`riskTolerance`、`industryExposure`、`liquidityNeeds`，每项最多4000字）。普通研究背景继续使用`portfolio`。六项字段齐备只是结构完整，还需要模型核实有效性；背景描述不自动授予具体仓位结论。

财报更新可从详情页发起，或在工作台选择旧报告。服务端检查旧报告完成状态与标的覆盖，保存最多60000字符的报告快照及结构化结论，并将旧引用标成历史来源。旧报告后续删除不影响已经创建的更新任务。未提供对照时只建立本期基线，不生成无依据的升级、降级或剔除判断。

估值工具要求记录币种、期间、股本口径、假设与有效来源编号，披露目录不能充作计算证据。市赚率增加支付率敏感性和0.4锚，周期股N修正默认关闭；例外须显式提供已核实条件及原因。工具验证数值和声明结构，不独立认证参数事实。

审计按主模式返回`sections`、`audit`和`decision`。程序检查必需章节、研究动作、五级置信度、至少三条不同的证伪条件、日期、数据/质量/估值/风险复核项、组合边界及正文来源编号。Deep评分只能使用25/15/25/20/5/10体系，缺失值保留null，正文评分由校验后的字段生成；市赚率变式不能充作多个独立估值方法。第一次交付不合格会要求一次修正，仍失败则不发布正式报告。这些是结构和边界校验，不代替事实核验，也不能保证模型对自然语言规则的遵循。

新报告的详情页展示研究动作、置信度、证伪条件和信息缺口；摘要中的`researchOutcome`供研究记录和最近研究展示。旧报告保持原有阅读、导出和输入复用能力，不补造结构化结论。

研究引擎记录明确问题、采集证据、分析查证、工具计算、复核交付五个阶段，并通过 SSE 的 `workflow` 事件更新详情。估值按需调用，未使用时明确标记；工具事件携带 `toolCallId` 与 `toolName` 关联输入和结果。最终报告额外保存结构化程序校验记录。计划与阶段随任务保存至 MongoDB；旧记录保持可读，不补造执行阶段。服务重启时未完成任务仍标记为中断失败。

工作台支持步骤定位、研究路径切换和 `Ctrl / ⌘ + Enter` 提交；选择股东回报模式时显示固定八年范围。研究记录可按问题、模式和证券信息搜索，高亮命中文字，状态筛选数量随搜索更新；按 Escape 清空关键词。列表支持排序、分页与手动刷新，有进行中的任务时每15秒更新。最近研究使用整项链接，突出当前记录并保留新标签页打开方式。详情的状态紧跟标题，桌面操作与标题同处一行并靠右对齐，整体吸顶；长标题省略显示，可悬停查看完整标题；报告、研究思路、审计、来源四个标签页保持相同的正文宽度，右侧保留执行轨迹。页签旁常驻报告目录入口，随页签一起吸顶；桌面使用浮层，手机和平板使用抽屉。在审计或来源页选择章节，会自动切回报告并定位到工具栏下方；没有章节时入口禁用。手机和平板的研究操作仍由标题下方入口打开，执行轨迹显示在正文下方。详情支持来源搜索与批量展开、执行事件筛选、已结束任务的输入复用；阅读模式仍可取消任务。按钮、卡片、标签、下拉选择和折叠区域复用现有 shadcn/ui 组件。
