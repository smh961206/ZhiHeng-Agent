# 知衡 · 价值投资研究 Agent

React + Node.js。将V4.1 CORE/FULL转为六类研究任务、证据检索、估值工具和模型审计。只使用自动抓取的数据，不预置研究结果。

## 启动

Linux Docker 一键部署、代码更新、数据库版本迁移与备份回滚见 [部署文档](DEPLOY.md)。配置 `.env.production` 后执行 `bash deploy.sh up`，后续执行 `bash deploy.sh upgrade`。

要求 Node.js **22.13+**、pnpm、已启动的 Docker Desktop（Linux 容器）。

```powershell
pnpm install
Copy-Item .env.example .env
pnpm db:up
# 在.env配置模型后运行
pnpm dev
```

开发页面 `http://127.0.0.1:5173`，后端 `http://127.0.0.1:3001`。

```powershell
pnpm build
pnpm start
```

构建后统一使用 `http://127.0.0.1:3001`。Windows也可运行 `./start.ps1`，优先系统Node，找不到时使用本机已有Codex Node运行时。本应用仅监听本机，无多用户鉴权，不应直接暴露到公网。

必须填写 `LLM_API_KEY`、`LLM_BASE_URL`、`LLM_MODEL`。模型需支持Chat Completions工具调用及按协议返回JSON。密钥只在后端读取；问题、组合信息、选用的历史研究快照和相关财报片段会发送给配置的模型服务。未配置模型直接报错。可设置 `SEC_USER_AGENT=应用名 真实联系邮箱` 以符合SEC来源访问要求。

## 使用与数据源

填写研究问题，添加最多3个证券代码（A股6位、港股1～5位、美股Ticker）。“查看行情”预览快照；“开始研究”重新获取行情并自动抓取官方财报。任务支持取消、执行轨迹、历史搜索、重载输入和Markdown导出。

| 市场 | 行情 | 官方财报 |
|---|---|---|
| A股 | 东方财富公开行情 | 巨潮官方代码目录、定期报告目录、PDF下载和逐页提取 |
| 港股 | 东方财富公开行情 | 巨潮官方平台港股披露、年报/中期报告等PDF |
| 美股 | Yahoo Finance公开行情，腾讯独立备用源 | SEC公司代码检索、Submissions目录、Company Facts官方XBRL核心事实 |

行情是**最新可得快照，可能延迟**，不是交易所逐笔直连。行情时间与抓取时间分开记录，休市显示最近交易行情。行情币种与财报币种分别验证，不默认港股财报为HKD。未核实口径的行情PE不自动用于估值。

财报历史范围3/5/8年；初筛读取最近披露加最近年报，其余模式读取最近4份披露加所选年数年报，股东回报默认8年。巨潮A股最多6页、港股每关键词3页，SEC最多补充2个历史目录；触及范围会标记，不保证所有历史覆盖。

PDF单文件32MB、解析90秒、最多600页/150万字符，记录页码和截断。扫描页不OCR，表格布局可能丢失，关键数字需核对原文。正文按URL缓存7天，保留下载时间、SHA256与页数；行情和披露目录重新查询。界面仅预览前12000字符，模型可检索已提取全文。

美股读取**官方XBRL核心财务数据，不是完整财报正文**。覆盖10-K、10-Q、20-F、40-F及修订；保留标签、单位、期间、比较期、申报号，不自动拼接TTM。6-K、管理层讨论、全部附注和未映射标签不在当前自动覆盖范围。来源页提供官方申报原件链接。

来源403/429、接口变化、抓取或解析失败均明确报错，不绕过限制、不编造数据。任一标的完全没有可读官方财报时停止模型研究；部分失败保留缺口。公开接口没有服务可用性保证，长期生产使用应接入授权数据商。

## 架构

- `src/main.jsx`、`DataConnect.jsx`：工作台、三市场证券输入、行情、报告和历史。
- `server/market-data.mjs`：来源白名单、超时/大小限制、SEC节流、代码匹配、抓取和缓存。
- `server/pdf-worker.mjs`：独立线程提取PDF，支持超时和取消。
- `server/agent.mjs`：10轮工具调用上限、证据检索、FULL规则检索、模型审计、来源ID检查。
- `server/calculations.mjs`：市赚率三公式、N修正、价格锚/ROE敏感性、FCFF/FCFE DCF、收益率锚。
- `server/index.mjs`：HTTP、任务管理、取消和静态资源。
- `server/storage.mjs`：MongoDB 任务索引、GridFS 完整任务内容、财报缓存及7天过期索引。
- `knowledge/`：用户原始CORE/FULL副本；`data/`：旧版 JSON 数据，只用于迁移，保留原文件。

## MongoDB 持久化

`compose.yaml` 部署官方 `mongo:8.0`，仅映射 `127.0.0.1:27017`，使用 Docker 命名卷 `zhiheng-agent_mongodb_data` 和 `zhiheng-agent_mongodb_config`，自动重启策略为 `unless-stopped`。本地开发不设数据库认证，请勿将端口暴露到公网。

默认连接 `mongodb://127.0.0.1:27017`，数据库 `zhiheng_agent`；可通过 `.env` 中的 `MONGODB_URI`、`MONGODB_DATABASE` 修改。数据库不可用时后端启动失败，不回退到文件存储。`GET /api/health` 检查实时数据库连接。

后端每次启动会导入 `data/*.json` 研究任务和 `data/cache/*.json` 未过期缓存。已有任务不会覆盖，旧文件不会删除；损坏文件会明确报错并阻止启动，修复后可重试。也可独立执行 `pnpm db:migrate`。请只运行一个后端实例；重启时将遗留的排队/运行任务标记为中断失败。

任务摘要保存在 `jobs`，完整任务保存在 `job_payloads.files/chunks`，支持超过16MB的研究资料；历史内容版本保留以保障并发读取。财报正文保存在 `report_cache`，读取立即过滤过期数据，TTL 索引异步清理。只有正在运行或保存失败的任务保留在内存供界面查看。

`pnpm db:stop` 停止数据库，`pnpm db:up` 恢复。普通容器重建保留数据；不要执行 `docker compose down -v`，该命令会删除持久化卷。备份可使用容器中的 `mongodump`，恢复使用 `mongorestore`。

`pnpm test:mongodb` 在随机命名的临时数据库验证大文本、重连持久化、任务恢复、缓存过期和幂等迁移，结束后清理测试数据库。实现参考 [MongoDB GridFS 文档](https://www.mongodb.com/docs/drivers/node/current/crud/gridfs/) 和 [MongoDB 官方镜像](https://hub.docker.com/_/mongo)。

业务适配和大部分研究审计仍由模型执行。数值工具不认证事实，官方采集不代表全部假设已核实。跨币种、正常化、历史覆盖、市赚率行业适配仍需复核；没有完整组合上下文不得输出具体权重。

## API与验证

- `GET /api/config`：非敏感配置。
- `POST /api/quotes`：`{securities:[{market:"CN"|"HK"|"US",symbol}]}`，逐标的返回行情或错误。
- `POST /api/jobs`：`{question,mode:"auto"|"A".."F",depth:"Quick"|"Standard"|"Deep",portfolio,securities,historyYears:3|5|8}`。
- `DELETE /api/jobs/:id`：删除已结束的研究及全部内容版本；运行中返回409，需先取消并等待结束。研究记录提供确认删除入口；最近研究仅提供最近4条记录的快捷打开，无记录时隐藏，删除记录不会被旧JSON重新导入。
- `GET /api/jobs`、`GET /api/jobs/:id`、`POST /api/jobs/:id/cancel`：列表、详情与取消。

`pnpm test` 覆盖公式、输入、行情精度、来源安全、XBRL期间和模拟工具闭环。测试常量只存在于测试文件，不进入应用。


ode scripts/data-smoke.mjs` 做真实三市场抓取测试，将元数据写入 `artifacts/data-smoke.json`，不调用模型、不建立研究任务。`scripts/smoke.mjs` 是可选Playwright真实行情界面测试，设置 `PLAYWRIGHT_MODULE` 为已安装Playwright入口。

依据：[巨潮资讯](https://www.cninfo.com.cn/new/index)、[SEC官方API](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)、[PDF.js](https://mozilla.github.io/pdf.js/examples/)、[OpenAI接口](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。
`LLM_TIMEOUT_MS` 控制单次模型请求超时，默认300000毫秒、允许30000～600000毫秒。审计使用独立精简上下文；未审计草稿不会作为最终报告展示。

## 问题自动填充与界面
输入公司名称或股票代码后，系统防抖查询巨潮与SEC官方证券目录，自动填入A股、港股、美股标的；两地上市或多股类会要求选择，无法识别时可手动调整。修改问题会清除旧的自动结果；手动调整后须点击“恢复自动识别”才恢复联动。点击“开始研究”后抓取行情与官方财报。

`POST /api/securities/resolve` 接收 `{question}`，返回证券、歧义候选、未识别项和来源警告。单次最多3个标的。

界面使用 [shadcn/ui](https://ui.shadcn.com/docs/installation/vite)、Radix与Tailwind，桌面侧栏和手机抽屉导航自适应；前端不再提供模型配置模块，模型参数统一在后端环境变量管理。


## 实时研究报告

`GET /api/jobs/:id/stream` 使用 SSE 推送当前快照、执行事件和报告增量，断线后浏览器自动重连并重新读取当前快照。离开页面不会取消任务。模型请求启用 `stream: true`，兼容工具参数分片；如果供应商仍返回完整 JSON，也可读取，但无法提供逐字输出。

生成中的内容仅作为未审计预览，审计通过后替换为正式报告；失败或取消时移除预览，导出仅对正式结果开放。执行轨迹按最新在前展示。反向代理需关闭 SSE 缓冲并允许长连接（例如 Nginx `proxy_buffering off; proxy_read_timeout 3600s;`）；服务发送15秒心跳。

草稿阶段只要求可阅读的 Markdown，JSON 交付协议仅用于独立审计阶段。前后端共用预览格式处理：去除包裹整篇报告的 Markdown 代码围栏，完整结构化草稿只提取报告章节，未完成或无法识别的结构化内容显示整理进度，不直接展示内部字段。前端同时兼容旧任务快照中的原始草稿。该处理只影响预览，原始草稿仍提交审计，正式报告仍须通过原有交付校验。

当前单实例以内存广播实时消息、MongoDB持久化任务和财报缓存，无需 Redis。若后续引入多个后端实例、独立任务进程或可靠任务队列，再设计共享任务状态和消息分发；普通 Redis Pub/Sub 不持久化断线消息，可靠重放可评估 Redis Streams。

## 页面路由与研究框架

平台使用 React Router 的浏览器路由：`/workbench` 为工作台，`/history` 为研究记录，`/framework` 为研究框架，`/research/:jobId` 为研究详情。详情标签页使用 `?tab=audit` 或 `?tab=sources`；记录的关键词、状态、排序、页码保存在查询参数中。部署服务器需将非 API 的页面地址回退到 `dist/index.html`，本项目 Node 服务已支持。

失败或已取消的研究可在详情页直接“重试研究”。`POST /api/jobs/:id/retry` 接收 `expectedRetryCount`（首次为0），从服务端保存的输入重新执行当前记录，保持研究ID、创建时间和详情地址不变，不增加研究记录。原问题、已确定的模式、深度、标的、年份、组合信息及已保存的历史对照快照沿用；旧错误、结果、行情、来源、草稿和阶段状态重置为本轮内容，并记录重试次数与最近重试时间。前端保持当前标签页并重新连接进度；桌面和移动端共用提交锁。服务端通过运行锁、容量预留和数据库条件更新防止并发重启、过期请求与已删除记录被恢复。写入失败时保留原状态，允许再次尝试。提交期间离开页面不会被强制跳回。已完成报告的“复用研究输入”仍只载入工作台，不自动提交。

研究框架页围绕公司质量、证据链、估值假设和证伪跟踪说明价值；六类场景可切换查看交付内容并进入工作台，五个流程步骤支持点击与键盘切换。两组标签默认从各自第一个标签开始，每4秒自动轮播，不显示独立控制按钮；悬停、聚焦内容、离开可见区域或切到后台时暂停，恢复后重新计时。遵循系统“减少动态效果”偏好，启用该偏好时仅手动切换标签。两组内容在切换时保持高度稳定，窄屏只横向移动标签栏以显示当前标签。评分区域只展示规则权重，不预置公司分数。页面与新增交互复用 shadcn/ui，支持320px手机及桌面。各页面底部重复的品牌文案已移除。

`knowledge/CORE.md` 与 `knowledge/FULL.md` 是业务依据。`shared/research-framework.mjs` 是其可执行映射，统一六类任务、必要辅助模块、五个阶段、六维评分和输出协议。`server/knowledge.mjs` 在启动时检查Skill版本与绑定章节；原文版本、日期与SHA256随计划和最终报告保存。规则检索返回完整小节、来源与行号，超出窗口会标记截断。修改Skill时需同步映射与验证，不能只修改宣传页面。

`POST /api/research/plan` 与任务创建共用输入校验、模式路由和历史对照检查，不调用模型。创建时重新生成并保存计划；A 初筛强制Quick，F 股东回报使用八年检索范围；长期价值研究中的分红问题保留B主模式并增加必要辅助模块。实际读取范围仍受来源覆盖限制，当前不自动展开指数成分或批量筛选全市场。

计划与创建API均新增可选字段：`previousResearch`（上次结论，最多30000字）、`baselineJobId`（已完成的同标的研究）、`portfolioContext`（`holdings`、`weights`、`assetRange`、`riskTolerance`、`industryExposure`、`liquidityNeeds`，每项最多4000字）。普通研究背景继续使用`portfolio`。六项字段齐备只是结构完整，还需要模型核实有效性；背景描述不自动授予具体仓位结论。

财报更新可从详情页发起，或在工作台选择旧报告。服务端检查旧报告完成状态与标的覆盖，保存最多60000字符的报告快照及结构化结论，并将旧引用标成历史来源。旧报告后续删除不影响已经创建的更新任务。未提供对照时只建立本期基线，不生成无依据的升级、降级或剔除判断。

估值工具要求记录币种、期间、股本口径、假设与有效来源编号，披露目录不能充作计算证据。市赚率增加支付率敏感性和0.4锚，周期股N修正默认关闭；例外须显式提供已核实条件及原因。工具验证数值和声明结构，不独立认证参数事实。

审计按主模式返回`sections`、`audit`和`decision`。程序检查必需章节、研究动作、五级置信度、至少三条不同的证伪条件、日期、数据/质量/估值/风险复核项、组合边界及正文来源编号。Deep评分只能使用25/15/25/20/5/10体系，缺失值保留null，正文评分由校验后的字段生成；市赚率变式不能充作多个独立估值方法。第一次交付不合格会要求一次修正，仍失败则不发布正式报告。这些是结构和边界校验，不代替事实核验，也不能保证模型对自然语言规则的遵循。

新报告的详情页展示研究动作、置信度、证伪条件和信息缺口；摘要中的`researchOutcome`供研究记录和最近研究展示。旧报告保持原有阅读、导出和输入复用能力，不补造结构化结论。

研究引擎记录明确问题、采集证据、分析查证、工具计算、复核交付五个阶段，并通过 SSE 的 `workflow` 事件更新详情。估值按需调用，未使用时明确标记；工具事件携带 `toolCallId` 与 `toolName` 关联输入和结果。最终报告额外保存结构化程序校验记录。计划与阶段随任务保存至 MongoDB；旧记录保持可读，不补造执行阶段。服务重启时未完成任务仍标记为中断失败。

工作台支持步骤定位、研究路径切换和 `Ctrl / ⌘ + Enter` 提交；选择股东回报模式时显示固定八年范围。研究记录可按问题、模式和证券信息搜索，高亮命中文字，状态筛选数量随搜索更新；按 Escape 清空关键词。列表支持排序、分页与手动刷新，有进行中的任务时每15秒更新。最近研究使用整项链接，突出当前记录并保留新标签页打开方式。详情的状态紧跟标题，桌面操作与标题同处一行并靠右对齐，整体吸顶；长标题省略显示，可悬停查看完整标题；三个标签页保持相同的正文宽度，右侧保留执行轨迹。页签旁常驻报告目录入口，随页签一起吸顶；桌面使用浮层，手机和平板使用抽屉。在审计或来源页选择章节，会自动切回报告并定位到工具栏下方；没有章节时入口禁用。手机和平板的研究操作仍由标题下方入口打开，执行轨迹显示在正文下方。详情支持来源搜索与批量展开、执行事件筛选、已结束任务的输入复用；阅读模式仍可取消任务。按钮、卡片、标签、下拉选择和折叠区域复用现有 shadcn/ui 组件。

界面回归检查：先启动前端，再运行 `pnpm test:ui`。默认访问 `http://127.0.0.1:5173`，可用 `UI_BASE_URL` 指定其他本机端口。需要已安装的 Playwright 与 Edge；`PLAYWRIGHT_MODULE` 可指定 Playwright 模块入口。测试拦截 API 并使用内存模拟数据，不调用真实模型或修改实际研究记录；结果与截图写入 `artifacts/ui-*`。
