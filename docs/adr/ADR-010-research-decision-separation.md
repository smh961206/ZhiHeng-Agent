# Research and Decision Are Separate

Status: ACCEPTED

## Decision

Company research does not directly equal buy/sell. Investment action requires mandate, opportunity cost, downside, uncertainty and portfolio context.

## Consequences

- Future releases must preserve this decision unless explicitly superseded.
- Codex must not “simplify” the architecture by violating this decision.
- If a current implementation cannot yet satisfy the decision, mark it PARTIAL/FUTURE and implement only in the owning release.

Implementation Status: PARTIAL. Portfolio context/readiness gates exist; canonical mandate-linked Decision is future.
