# Research Lifecycle

## Current lifecycle to preserve

Create → Plan → Acquire → Parse → Retrieve → Analyze → Calculate → Supplement → Review → Validate → Save/Deliver.

Checkpoint/resume is part of the lifecycle, not an optional add-on.

## Target lifecycle

```text
Intent
→ Research IR
→ Hypothesis / Claim Plan
→ Knowledge Resolution
→ Data Acquisition
→ Security Resolution
→ Evidence
→ Fact Verification
→ Calculation
→ Counter-evidence
→ Belief Update
→ Forecast / Scenario
→ Valuation
→ Decision Readiness
→ Portfolio Context
→ Validation
→ Research State
→ Renderer
```

## Long-term event update

```text
New Event
→ Materiality
→ Affected Facts
→ Dependency DAG
→ Affected Claims / Beliefs
→ Valuation Delta
→ Decision Re-evaluation
→ Research Delta
```

Current releases must preserve the current lifecycle until their replacement contracts are accepted.

## H0 calibration

CURRENT: public plans/receipts, bounded tools, independent review, validation, durable delivery and compatible checkpoint resume. Restart and in-memory unsaved-delivery limits are documented in [audit findings](../releases/H0/audit-findings.md). Target and long-term flows above are FUTURE, not current canonical objects.
