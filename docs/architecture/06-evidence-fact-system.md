# Evidence / Fact System

## Evidence

Evidence is a source-grounded observation/passage/table/image reading usable to support or refute research.

## Fact

A Fact is a normalized assertion with explicit:
- entity;
- metric;
- period/time;
- value;
- unit/currency;
- scope;
- epistemic state;
- source lineage;
- revision state.

## Permanent distinction

Evidence says what a source contains.

Fact says what ZhiHeng has normalized/verified from evidence.

Forecast and assumptions are not facts.

## Target retrieval

Structured + Exact + BM25 + Semantic + Page/Table → Fusion/Rerank → Evidence Pack.

Embedding increases semantic recall. It does not replace exact financial retrieval.
