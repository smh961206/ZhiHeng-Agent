# Forecast / Decision / Portfolio

## Forecast

Future values should be driver-based where possible and explicitly depend on assumptions.

## Scenario

A coherent set of assumptions/world states. Base/Bull/Bear is the first implementation; scenario trees are later.

## Decision separation

Research quality and investment action are different questions.

Decision = Research State + Investment Mandate + Expected Return + Risk + Opportunity Cost + Portfolio Context.

## Cash

Cash is a legitimate asset/opportunity, not merely “unused allocation”.

## Portfolio

Portfolio intelligence eventually includes:
- sector/market/currency/factor exposure;
- liquidity;
- price correlation;
- thesis/assumption correlation;
- hidden business/macro exposure.
