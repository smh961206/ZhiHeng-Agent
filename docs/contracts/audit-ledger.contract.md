# Audit Ledger Contract
Implementation Status: FUTURE; target V6.0.

Audit events include:
fact verification/revision, Knowledge publication, human override, critical claim change, model escalation, research publication, decision creation.

Audit history must be append-oriented and traceable.

## Current implementation evidence

Job events, Knowledge usage receipts and retained payloads exist; they are not a canonical immutable audit ledger or human-override registry.

See the [current implementation map](../architecture/current-implementation-map.md). This contract text alone changes no persisted object, field requirements, API, migration or financial meaning.
