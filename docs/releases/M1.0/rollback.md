# M1.0 回滚说明

回滚前保留当前 schema v2 模型文件和任务数据。将 `MODEL_CONFIG_FILE` 改回可用的 schema v1 文件并恢复对应旧环境变量，然后重启服务。此操作只影响之后创建的任务。

modelState v4 任务不得在不支持 v4 的旧运行版本中继续执行，也不得静默改绑 schema v1 模型。需要继续这些任务时，应恢复支持 M1.0 的运行版本和原配置身份。modelState v1-v3 任务可继续按原状态恢复。

回滚不删除模型调用、成本、缓存、历史预算账本、关键复核、Judge、证据或审计记录。历史预算账本只用于兼容恢复，不应重新启用额度限制。若生产配置仅是模型密钥轮换，保持相同 `apiKeyEnv`、模型和接口身份即可，无需回滚任务状态。
