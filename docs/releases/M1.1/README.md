# M1.1 — Token-efficient stage contexts

状态：M1.1.0–M1.1.3 已实施

M1.1 phase 1 keeps the V5.2 research, evidence, calculation, audit and recovery contracts while reducing repeated model input for new schema-v2/modelState-v4 tasks.

Implemented:

- automatic, network-free serialized tool-definition footprint check;
- total and per-stage input/output/cache Token summaries from normal ModelCall telemetry;
- research-path tool sets for A–F and prerequisite-aware advanced valuation tools;
- detailed shareholder rules only for relevant paths or explicit shareholder-return intent;
- Quick, Standard and Deep safe compaction profiles after complete tool rounds;
- separately rebuilt Writer context with citation/calculation integrity receipts;
- additive `modelState.contextVersion=1` pin for new tasks, with unchanged request wire for modelState v1–v3 and pre-M1.1 v4 jobs.
- synchronized platform copy and interaction: the workbench explains the selected path in investor language; the right-top status, home and handbook omit internal platform/model-track versions; research details prioritize research basis, progress and source coverage while keeping saved model assignment and actual call/Token records in an on-demand advanced section.

Not included in phase 1:

- token or price budgets;
- paid trials or manual model acceptance;
- Champion, Challenger or A/B routing;
- Auditor repair-loop delta packets;
- Vision request changes;
- cross-task or cross-period research reuse.
