# V4.9 平台前端同步与交互优化

日期：2026-09-11。范围为用户授权的整体前端文案、样式与交互同步。按照已落地的文档与图像读取能力更新页面，保持绿色视觉体系，不将平台版本、模型配置或读取完成等同于事实核实。

## 变更与验收记录

1. **版本**：V4.9 前端同步，CURRENT 保持 V4.9。V4.9 实现与离线验证、真实候选质量及生产准入分别表述；本轮不接受或启用新的模型策略。
2. **修改文件**：src/components/PlatformStatus.jsx、ResearchFramework.jsx、ResearchCapabilities.jsx、ResearchWorkbench.jsx、ResearchMaterials.jsx、ResearchHistory.jsx、ResearchHandbook.jsx、ResearchUsageGuide.jsx、ResearchMethod.jsx、DocumentReadingSummary.jsx；src/components/research-usage.css、src/platform.css；tests/platform-v48-ui-scenarios.mjs、tests/workspace-ui.integration.mjs；docs/architecture/current-implementation-map.md、docs/releases/V4.9/DETAILED_INDEX.md、MANIFEST.json。
3. **新增文件**：src/config/platform-release.mjs、tests/platform-v49-ui-scenarios.mjs、本报告。忽略的 artifacts/v49-frontend/ 留存开始时副本、哈希、日志及截图。
4. **删除文件**：无。没有删除测试、跳过原验证或降低证据要求。
5. **架构**：复用现有页面与资料组件；小型前端配置统一公开功能版本，研究规则仍读取原 frameworkVersion，历史模型记录仍来自保存的 job.modelRouting。使用指南沿用现有六个主题，通过 URL 片段控制展开、聚焦和滚动，不另建文档或导航子系统。没有新后端 API。
6. **Schema**：无。版本展示、指南展开集合和定位偏移均为前端配置或临时状态。
7. **迁移**：无。历史报告、提取结果、规则与模型记录不回填、不重写。
8. **环境**：依赖不变；本轮在 127.0.0.1:5194 运行隔离开发预览，5195 运行正式构建预览，验证结束后停止自己的服务。数据库使用既有 27029 测试服务和随机隔离库，没有生产发布。仓库期间另有后端维护变更，见下方兼容性说明。
9. **兼容性**：顶部与首页同步 V4.9，当前规则仍为 V4.7，历史 V4.3/V4.7/缺失版本仍按保存记录展示。移除平台说明内额外的版本折叠层；保持未知、未配置、不匹配等状态和原创建阻断。文件格式、大小、页数、资料数量限制及原页关联语义不变。没有从私有运行时提取新增模型元数据。
10. **恢复**：保留研究恢复、原时点、导出、只重试保存及草稿保存逻辑。指南链接可直接打开目标章节；同一链接再次点击可重新展开，浏览器返回和刷新仍能定位。资料准备指南在新标签页打开，避免中断正在导入的文件。
11. **Feature flags**：无新增、修改或开启。未触发付费比较或候选模型晋升。
12. **测试执行**：完整单元、路由、15 项 MongoDB/恢复集成、301 个完整界面场景、正式构建与 20 项正式构建浏览器检查；文档及清单最后由 Harness 校验。命令及证据见下表。
13. **测试结果**：单元复测快照 789/789，路由 5/5；界面三组 101/101、100/100、100/100，无缺失场景；正式构建浏览器 20/20。集成初次 14 通过、1 超时取消，超时的创建流程单独复测 1/1，原断言与 20 秒限制未修改。不是将首次集成运行标为全部通过。随后另有模型配置维护修改后端和文档，仓库级 Harness 最后一次运行 5/7：新增引用文档尚未生成、其他维护条目哈希未同步，本轮前端文件哈希未变化；因此不宣称当前整个工作区全部验收通过。
14. **Benchmark**：未调用真实模型或做质量/成本测量。正式构建主入口 550.71 kB / gzip 182.22 kB；超过 500 kB 的提醒保留，没有提高阈值。此处只记录包体，不声称改善网络时延或模型质量。
15. **安全与隐私**：UI 全部 API 使用内存夹具，数据库测试使用隔离临时记录；没有真实研究提交。页面强调图像读取不等于核实、模糊输入保留缺口、配置不表示调用，不暴露内部推理或凭据。
16. **回滚**：使用 artifacts/v49-frontend/before/ 与 completion.json 审核，只撤回本报告列出的前端、测试和文档增量；新文件可随增量撤回，同步调整 MANIFEST 条目和哈希。不要全仓 reset，也不要覆盖其他 V4.9 后端维护；无需数据库回滚。
17. **已知限制**：公开接口和历史任务没有保存的逐次提取配置/身份不会被页面推断或补写。手册说明不保证文件逐页全覆盖。包体提醒和真实网络性能测量仍待后续工作。单元首次检查遇到 Vision 源码审查指纹不同步，维护同步后完整复测通过；日志保留，未通过修改测试或由本轮重写指纹来绕过。集成超时没有在单独复测中重现，不声称已证明其所有可能原因。
18. **延期工作**：真实候选模型质量准入、V4.8 付费试跑、生产模型策略切换与 V5.0+ 仍不在本轮范围。

## 用户可见变化

- **首页与平台说明**：统一功能版本，说明报告、表格与截图如何参与研究；版本解释直接可见，配置与可用性分开表述。
- **工作台与补充资料**：精简问题说明；增加保留表头、单位、报告期间和脚注的准备提示，直接连接到对应指南。已有文件预览、编辑、失败重试、导入进度与限制保持。
- **研究记录**：引导用户回查原始资料和读取范围；键盘聚焦时强化当前行，保留筛选、排序、状态和恢复入口。
- **手册**：六个主题提供快速定位，选中章节自动展开和聚焦；手机标签为两列，避免四个标签分成三加一。定位偏移依据固定标签栏的实际高度计算，章节标题不会被遮挡。
- **研究详情**：原页复核说明增加“看读取范围 → 对照关键数字 → 回查来源”的阅读顺序；模型配置与实际复读范围分开呈现。缺失、部分未纳入和交付被拒绝的旧记录各有明确说明，未新增折叠层或彩色滚动条。
