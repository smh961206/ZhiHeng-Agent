# V4.9.5 完成报告

新增 server/vision-quality.mjs，独立的纯确定性视觉表格评分器；它不属于财务 Fact／计算逻辑。按数值、单位、日期、表头、符号、括号、脚注、行列关系和缺失分别评分，任何关键错误都不能由其他维度平均分掩盖。十进制使用字符串／BigInt 规范化，不发生大整数浮点取整；空白／未读清为 null，真实零单列。

新增 tests/vision-quality.test.mjs、本报告；无其他生产调用接入、删除、schema、迁移、环境、flags、API 或恢复改变。纯评分不外发资料，无模型推理／私有信息持久化。

评分／冻结输入／既有视觉与证据回归共 24 个通过。测试覆盖 48 个参考答案自一致（只校验 grader，不证明模型质量）、大整数、符号与括号、列交换、单位／期间／脚注错误、重复或伪造单元格、missing→0、无效 JSON。首次测试发现无效输入的 passed 为 null，改为显式 false 后通过，未放宽断言。

回滚删除本阶段纯评分器／测试即可，无历史数据影响。限制：严格结构化答案／英文标签，非自由文本语义裁判；合成语料不是完整真实研究质量保证。V4.9.6–.8 候选／fallback／准入待后续。
