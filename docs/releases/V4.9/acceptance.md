# V4.9 Acceptance Contract

A release is not complete because code compiles. These behaviors must hold.

### VIS-001

Text-only profile cannot receive images.

### VIS-002

Existing image/page/request limits stay enforced.

### VIS-003

Vision numeric reading remains unverified until existing verification path.

### VIS-004

Unreadable image does not trigger endless provider cycling.

### VIS-005

Primary switch requires benchmark gate.


## Global gates
- Existing relevant tests pass.
- New release tests pass.
- No P0 evidence/fact/point-in-time/calculation regression.
- Resume/recovery behavior remains valid.
- Rollback path is documented and testable.
