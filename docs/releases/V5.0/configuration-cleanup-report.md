# V5.0 模型配置分层与当前状态展示

用户在配置分层建议后确认“好”，授权整理基础／高级示例和页面状态。既有真实验收暂停、模型启用与历史任务身份约束继续有效。

## 改动

当时的基础模板保留默认研究、路径识别、视觉模型以及固定模式和调用记录设置；MAIN/PRO、视觉候选、MAIN 候选、A/B 与批准路径曾移到单独的高级示例。该布局现已归并；批准路径仍为空，可选发布开关仍关闭，原字段读取继续兼容。

既有 config 接口增加四字段公开摘要，由现有准入与视觉模块核对：新研究的有效模式、固定研究模型、可用视觉配置、是否采用候选策略。自适应模式不猜测某项任务实际选中的模型；旧后端或状态未知时显示未确认。页面不展示未启用候选名称、内部策略、路径、密钥或实验分组。摘要不是连通性实测，已有任务继续以保存记录为准。
