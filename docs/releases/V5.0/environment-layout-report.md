# V5.0 五份环境配置整理

用户明确要求分别整理 `.env`、`.env.example`、`.env.models.example`、`.env.production`、`.env.production.example`。本次仅调整注释、分组、空行及字段顺序；两份实际配置的赋值原文与全部解析值均保持一致。

## 文件职责

| 文件 | 用途与整理方式 |
|---|---|
| `.env` | 本地实际配置；服务、模型、资料服务在前，已存在的高级策略集中在末尾 |
| `.env.example` | 本地基础模板；按运行用途分组，说明密钥、继承规则及可选项 |
| `.env.production` | 生产实际配置；明确宿主机访问参数与容器参数的区别，保留已有高级配置 |
| `.env.production.example` | 生产基础模板；与本地模板共享字段顺序和说明，保留生产特有配置 |
| `.env.models.example` | 按 MAIN／PRO、视觉候选、MAIN 候选、任务优选与 A/B 四组整理，说明按需合并方式 |

相同字段使用统一中文说明。未新增、删除或改名任何变量。实际文件缺少的可选字段继续使用原有缺省行为，没有为了与模板对齐而插入配置。高级模板依然不会自动加载，两份实际配置中已有的高级字段继续由原文件加载。
