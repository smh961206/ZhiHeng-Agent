# V5.0 平台前端同步与交互优化

日期：2026-09-11。用户授权在 V5.0 工程迭代后同步平台文案、样式与交互。对照 CURRENT、V5.0 发布规范、当前可执行实现、模型契约与质量优先 ADR，说明模型评估能力，不将工程完成表述为真实质量验收或生产候选已启用。真实验收、付费测试与生产切换继续保持用户此前的暂停决定。

## 用户可见变化

- 首页沿用现有研究入口与视觉体系，将版本主题更新为“模型评估 · 质量优先”，增加直达评估说明的入口。
- 平台说明区分质量评估、资料读取和恢复兼容性。帮助链接明确在新标签页打开，保留工作台输入与当前处理页面。
- 手册新增直接可读的“同题对照 → 质量优先 → 验收后启用”说明。桌面三列、手机单列，无新增折叠层；直达链接定位时避开固定标签栏，并支持返回与刷新。
- 工作台说明研究路径与模型配置的区别；记录页强调回查当时依据；指南补充本次模型、规则与实际调用的核对方式。
- 详情保留任务原有模型与规则，明确平台更新不会补写旧配置或评估分数。空值仍显示“未记录”，长名称可以换行。
