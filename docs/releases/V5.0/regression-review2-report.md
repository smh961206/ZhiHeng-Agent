## 发现与修复

**漂移对比命令会忽略重复和未知参数。** 原实现通过 `indexOf` 取第一个参数值；例如在合法命令后再写一次 `--out another.json`，仍返回成功并重新写入第一个输出路径，而非拒绝含糊的请求。参数拼写错误也可能被忽略。

先扩展现有 CLI 回归测试，在有效冻结夹具上复现重复 `--out` 返回 0、预期为 1 的失败，保留 `drift-before-fix.log`。修复后，五个必需参数各出现一次且路径非空；重复、未知、缺值、空值或额外位置参数在读取输入或写入输出前被拒绝。测试同时检查已有报告字节不变、非预期输出文件不存在；合法比较和原有失真结果拒绝测试仍保留。定向 11/11 通过，见 `drift-after-fix.log`。

沿用现有命令和漂移计算模块，没有新增解析子系统，也没有修改评分、阈值、模型请求、Champion 注册表或研究执行逻辑。
