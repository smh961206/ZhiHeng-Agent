# V5.11 — Reproducibility / Learning / Institutional Memory

Status: FUTURE until CURRENT is changed to this release

## Goal

Make historical research replayable and turn outcomes/failures into governed system learning.

## Subrelease sequence

- **V5.11.0 — Research Snapshot:** Freeze Evidence/Fact/Knowledge/Market/Policy/Formula versions.
- **V5.11.1 — Point-in-time Replay:** Re-run with historical information cutoffs.
- **V5.11.2 — Research Provenance ID:** Hash/version manifest.
- **V5.11.3 — Failure Registry:** Structured root cause, severity, fix and regression.
- **V5.11.4 — Decision Journal:** Record action/reason/assumptions/invalidation/horizon.
- **V5.11.5 — Outcome model:** Business/market/claim-resolution outcomes.
- **V5.11.6 — Attribution:** earnings/multiple/dividend/buyback/FX/unexpected events.
- **V5.11.7 — Calibration:** Belief/decision confidence vs realized outcome.
- **V5.11.8 — Institutional Memory:** Research/failure/conflict/decision memory.
- **V5.11.9 — Research Genealogy:** Initial→earnings update→thesis revision etc.
- **V5.11.10 — Structured Diff:** Fact/Claim/Belief/Assumption/Valuation/Decision diff.
- **V5.11.11 — Offline policy/Knowledge learning:** Candidate changes only after benchmark/human approval.

## Scope lock

Only the items described by this release and its subreleases are in scope.

Future release concepts may be referenced for compatibility, but may not be implemented opportunistically.
