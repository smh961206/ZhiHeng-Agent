# Python 后端工程化方案

状态：Complete — 2026-09-14
发布线：Platform V5.3 / Knowledge K1.0.0

## 目标与结果

后端运行时、业务能力、迁移命令、基准和后端测试统一到 Python。React/TypeScript 只保留前端、`src/domain/` 客户端展示规则及必要构建工具。`server/`、跨运行时 `shared/` 和旧 Node 基准已删除，生产镜像最终阶段不包含 Node。

## 分层架构

```text
python_backend/
├── api/             # HTTP/SSE、Schema、中间件和安全边界
├── application/     # 用例、研究编排、恢复、Knowledge 和端口
├── domain/          # 业务模型、不变量、证据与确定性财务规则
└── infrastructure/  # MongoDB/GridFS、模型、行情、文档和官方来源适配器
```

依赖方向由架构测试约束：业务层不能直接调用模型提供方；适配器不能成为业务定义；`app.py` 只保留 ASGI 外观。

## 已落地能力

1. FastAPI 应用工厂、生命周期、统一异常、请求 ID、Origin/Host、请求体、速率和超时限制。
2. Pydantic Settings 与强类型请求、响应、持久化和领域模型；配置启动时集中校验并冻结。
3. MongoDB + GridFS 乐观版本、写入补偿、旧载荷清理、任务租约、结构版本和可恢复任务查询。
4. 研究任务幂等创建、并发限制、取消、重试、SSE、阶段检查点、完整管线快照和精确恢复。
5. K-Series 不可变快照、哈希校验、任务固定、检索和读取回执。
6. 模型候选质量排序、健康阻断、同次调用故障转移、安全错误、流式完整性和不含提示词的遥测。
7. SEC、CNINFO、HKEX 官方证据，Tushare/LongPort 补充数据，以及只读取监管机构或显式绑定发行人域名的网页正文；搜索摘要不进入证据。
8. MongoDB 公共数据完整性归档复用旧集合和摘要格式；收入、净利润、权益、经营现金流、资本开支及可复现派生指标进入主流程。需要假设而输入不足的估值继续保持缺失。
9. 原生文档解析与扫描 PDF 视觉兜底；视觉内容始终待复核，不能直接升级为已验证财务事实。
10. JSON 结构化日志、请求与模型指标、敏感字段清洗和 `/api/metrics`。
11. 锁定的生产/开发依赖、Ruff、mypy、pytest 覆盖率门槛、Python 迁移基准与 CI。
12. 研究上下文按证券/来源公平选择并受 220,000 字符上限约束，回执记录进入和省略的证据与材料；审查输出经强类型合同、引用、截止日、缺口和模式动作复核。
13. 真实 MongoDB 竞争/清理/租约/取消/墓碑/归档验收，以及 Docker 构建、启动、健康检查、Linux LongPort SDK 和无 Node 镜像验收。

## 工程边界

- 缺失、未核验、视觉提取、预测、观察和已验证事实保持不同语义。
- 点时截止、来源、币种、期间、股本和会计范围必须随数据流传递。
- 任务恢复固定原截止日、Knowledge 指纹、执行兼容标识和完整管线状态。
- 供应商适配器不得进入业务模块；新增供应商须提供契约测试。
- Prompt、隐藏推理和密钥不写入公共执行历史或模型遥测。
- 外部事件总线等分布式设施只在出现真实多实例需求时引入。

## 仍需部署环境验证的事项

真实模型调用、生产第三方凭证、外部站点的生产配额和网络策略无法由离线仓库验收替代。实现已通过受控契约测试并采用失败关闭策略；上线时需用部署环境配置执行冒烟测试。OpenTelemetry 导出器可以在确有集中追踪平台时追加，当前 JSON 日志和内部指标已覆盖单体运行诊断。
