# V5.7 — Hypothesis / Belief / Forecast / Research State

Status: FUTURE until CURRENT is changed to this release

## Goal

Move from one-shot report reasoning toward explicit competing hypotheses, calibrated beliefs, driver forecasts/scenarios and canonical Research State.

## Subrelease sequence

- **V5.7.0 — Hypothesis objects:** Multiple competing explanations with support/counter evidence.
- **V5.7.1 — Belief objects:** Prior/current probability and uncertainty type.
- **V5.7.2 — Uncertainty taxonomy:** data/model/structural/future/irreducible routing.
- **V5.7.3 — Driver forecast V1:** Revenue/Margin/FCF driver chains.
- **V5.7.4 — Scenario V1:** Base/Bull/Bear coherent assumption sets.
- **V5.7.5 — Reverse valuation:** Reverse DCF/PE implied assumptions.
- **V5.7.6 — Research State V1:** Canonical thesis/claims/beliefs/facts/assumptions/valuation/risk/catalyst/gap state.
- **V5.7.7 — State renderer:** Report rendered from state behind flag; legacy fallback.
- **V5.7.8 — Research IR design integration:** Compile plan into machine-readable IR only if explicitly activated in this subrelease.
- **V5.7.9 — Decision-readiness inputs:** Expose unresolved critical claim/uncertainty coverage without making decisions yet.
- **V5.7.10 — Calibration data collection:** Record probabilistic predictions for later V5.11 calibration.
- **V5.7.11 — Scenario-tree reservation:** Prepare schema only; advanced trees remain deferred unless separately scoped.

## Scope lock
