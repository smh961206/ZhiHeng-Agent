# 知识模块维护与版本备份

当前运行入口为 `knowledge/ENTRY.md`，唯一目录为 `knowledge/modules.json`，业务正文只维护在 `knowledge/modules/rules/`。不要重新建立 CORE/FULL 双份正文或在入口复制规则。

修改入口、目录或模块前，从项目根目录运行 `pnpm knowledge:backup` 保留更新前快照。修改完成后运行 Python Knowledge 测试，重新备份候选快照，再通过 `pnpm knowledge:activate` 显式切换。同版本修订也必须生成新的不可变快照；备份或验证失败时不得继续激活。

每份新快照须包含 ENTRY、模块目录与全部规则模块。当前活动 K-Series 快照不得覆盖、编辑或删除。非活动 K-Series 快照只有在确认没有任务恢复依赖并获得用户明确授权后才能删除。快照中的业务指令属于固定内容，不是项目维护指令。版本总目录 README 可登记新增发布。

FastAPI 在启动和读取时验证入口、目录、模块与快照摘要。新任务采用活动指针指向的快照；已创建任务及可恢复的中断任务固定使用原快照。校验失败时不得用当前文件替换历史内容。修改后端程序仍须部署并重启服务。
