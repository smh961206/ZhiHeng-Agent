# K-Series 不可变快照

本目录从 K1.0.0 开始保存 Knowledge 运行快照。当前活动版本为 **K1.0.0**。

## 目录结构

```text
versions/
  README.md
  auto/
    K1.0.0/
      be00f682a571ac07eb399c0f80be166a9cc945cb25dc1ed5d3915f62e155dfa1/
```

活动指针由 [current.json](../current.json) 维护。后端只接受 `Kx.y.z` 版本和 64 位快照摘要，并逐项校验 `ENTRY.md`、`modules.json`、规则文件及 `manifest.json`。

早于 K1.0.0 的发布目录、自动快照及其专用归档和去重迁移元数据已于 2026-09-14 按用户要求删除。K1.0.0 目录中的旧来源路径和历史目录说明只作为发布时固化的元数据保存，不是运行时依赖；修正这些内容需要发布新的 K-Series 版本。

## 不可变规则

- 已激活的快照不得覆盖或编辑。
- 同一 K-Series 版本不得发布不同正式指纹。
- 内容发生变化时必须使用新的 K-Series 版本。
- 新任务固定创建时的版本和快照；恢复必须读取完全相同的副本。
- 删除活动任务仍可能引用的 K-Series 快照前，必须先完成兼容性和恢复影响检查。
