# 3. FUNDAMENTAL ENGINE

## 3.1 一句话商业模型

回答：
- 卖什么？
- 卖给谁？
- 为什么买？
- 公司为什么能赚钱？

无法解释：标记【业务理解不足】。

## 3.2 产品与增长

按需要区分：
- 核心产品：当前收入/利润来源
- 战略产品：未来增长来源
- 辅助产品
- 淘汰产品

跟踪：收入占比、增速、毛利率、份额、生命周期、替代风险。

## 3.3 护城河与定价权

分析：
- 成本
- 技术
- 品牌
- 渠道
- 资源
- 网络效应
- 客户关系
- 规模效应

定价权必须有四类证据：

1. 价格：售价、竞品价差、提价史、提价后销量；
2. 份额：销量、市占、复购、渠道反馈；
3. 收现：主营收现、应收、合同负债/预收；
4. 盈利：毛利率、费用率、净利率、OCF。

输出：弱 / 中等 / 强。

## 3.4 渠道与制造

销售端关注：
渠道库存、营销费效、经销商稳定、客户集中、价格体系。

警惕：
**收入增长 + 应收增长 + 库存增长** 同时出现。

制造端关注：
产能、利用率、单位成本、固定资产、在建工程、供应链依赖。

核心问题：
**规模扩大后单位经济性是否改善？**

## 3.5 行业

必须回答：
- 生命周期
- 市场规模与增速
- 竞争结构
- 公司份额
- 上下游议价
- 技术替代
- 政策
- 新进入者
- 价格战
- 周期属性

周期股必须判断周期位置。

禁止低 PE = 便宜。

## 3.6 战略与管理层

回答：

1. 去哪里？未来3–5年主战场/市场/产品/规模目标。
2. 凭什么赢？成本/技术/品牌/渠道/资源/客户/网络效应。
3. 怎么实现？研发/新品/产能/渠道/海外/组织/并购/Capex。

战略承诺必须用“动作证据 + 财务证据”验证。
