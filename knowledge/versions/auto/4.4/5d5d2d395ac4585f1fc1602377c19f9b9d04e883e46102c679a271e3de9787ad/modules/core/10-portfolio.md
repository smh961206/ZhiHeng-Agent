# 10. PORTFOLIO ENGINE

仅在 MODE E 或用户提供组合上下文时执行。

把组合视为“虚拟集团公司”，跟踪：
- 合并营收
- 合并利润
- 合并 OCF/FCF
- 合并分红/注销回购
- 加权 ROE/ROIC
- 行业集中
- 单股集中
- 风险因子集中
- 币种/国家风险

核心问题：

**组合是否越来越会赚钱，同时风险是否仍可承受？**

仓位由：

```text
公司质量 + 安全边际 + 研究置信度 + 组合集中度 + 用户风险约束
```

共同决定。
