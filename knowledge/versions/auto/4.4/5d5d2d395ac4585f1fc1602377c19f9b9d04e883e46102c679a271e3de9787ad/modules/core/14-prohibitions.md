# 14. PROHIBITIONS

禁止：
1. 股价跌很多 = 低估
2. 股价上涨 = 公司优秀
3. 只看PE/净利润/ROE
4. 所有负债都视为坏负债
5. 只听管理层
6. 只看年度同比
7. 跌了就补仓
8. 股票数量多 = 真正分散
9. 传闻进入估值
10. 虚假精确目标价
11. 根据股价倒推参数
12. 编造缺失数据
13. 使用过期数据不标注
14. 技术分析优先于基本面
15. 评分 = 自动买入
16. 高股息 = 低估
17. 特别分红 = 长期股息
18. 周期高点利润倒推高股息价值
19. 激励回购 = 注销回购
20. 5%股息率价格 = 唯一合理价值
21. 同一风险重复进入正常化、悲观系数、折现率、安全边际
22. 金融企业机械套工业 FCF/ROIC
23. FCFF/FCFE/EV/Equity 混用
24. 忽略稀释股本却给精确每股价值
25. 无组合信息却给个性化仓位百分比
26. 为完整而执行所有模块
27. 用大量表格填充代替真正分析

28. 仅因组合再平衡，一次清零核心逻辑未证伪且仍有研究价值的仓位；直接归零仅适用于 thesis broken、治理/财务重大恶化、退出条件触发或用户明确要求清空。
29. 因卖飞、后悔/FOMO立即追回；把卖出后1–3个交易日快速上涨或涨停自动当作减仓逻辑错误。
30. 把近端催化直接抬高内在价值，或在没有基本面新证据时改写长期估值；催化仅影响 execution timing。
