# 4. FUNDAMENTAL ENGINE：业务、产品、行业、护城河、战略

## 4.1 一句话商业模型

必须回答：
- 公司卖什么？
- 卖给谁？
- 客户为什么愿意买？
- 公司靠什么赚钱？

无法解释时：
【业务理解不足】。

## 4.2 产品矩阵

按需要区分：
- 核心产品：当前主要收入和利润来源
- 战略产品：未来增长来源
- 辅助产品：增强核心业务竞争力
- 淘汰产品：主动退出的低效业务

跟踪：
- 收入占比
- 增速
- 毛利率
- 市场份额
- 生命周期
- 替代风险

## 4.3 产品竞争优势

分析：
- 成本优势
- 技术 / 工艺 / 专利 / 性能
- 品牌
- 渠道
- 资源禀赋
- 网络效应
- 客户关系

最终必须落到：

**竞争优势是否转化为可验证的经济利益。**

## 4.4 定价权证据链

禁止因为“品牌强”直接判断有定价权。

至少寻找四类证据：

1. 价格能力：售价、竞品价差、提价史、提价后销量
2. 市场份额：销量、市占、复购、渠道反馈
3. 收现能力：主营收现、应收、合同负债/预收
4. 盈利能力：毛利率、费用率、净利率、OCF

输出：
- 定价权弱
- 定价权中等
- 定价权强

必须附证据。

## 4.5 销售、渠道与制造

销售端：
- 直营 / 经销 / 电商 / 海外 / 大客户 / 政企
- 渠道库存
- 营销费效
- 经销商稳定性
- 客户集中度
- 价格体系

警惕：

**收入增长 + 应收增长 + 库存增长** 同时出现。

制造端：
- 自主制造 / OEM / 混合
- 原材料
- 人工
- 产能
- 产能利用率
- 单位成本
- 固定资产与在建工程

核心问题：

**规模扩大后，单位经济性是否改善？**

## 4.6 商业模式判断

重点识别：
- 定价权
- 规模效应
- 网络效应
- 品牌 / 技术 / 资源壁垒
- 收费权 / 类租金
- 资本强度
- 现金转化能力
- 再投资回报率

优先关注：

**高资本回报 + 高现金转化 + 合理资本消耗 + 可持续增长。**

## 4.7 行业分析

必须回答：
- 生命周期
- 市场规模
- 行业增速
- 竞争结构
- 公司市场份额
- 上游议价
- 下游议价
- 技术替代
- 政策
- 新进入者
- 价格战
- 周期属性

周期行业必须判断：
**当前更接近周期高位、中枢还是低位。**

禁止用低 PE 直接判断周期股便宜。

## 4.8 战略与管理层执行力

回答：

### 去哪里？
未来 3–5 年的主战场、目标市场、产品方向、规模目标。

### 凭什么赢？
成本、技术、品牌、渠道、资源、客户关系、网络效应。

### 怎么实现？
研发、新产品、新产能、新渠道、海外、组织调整、并购、资本开支。

建立“战略承诺表”：

| 战略承诺 | 应看到的动作 | 财务/经营证据 | 当前兑现 | 风险 |
|---|---|---|---|---|

管理层说什么 ≠ 一定做到什么。
