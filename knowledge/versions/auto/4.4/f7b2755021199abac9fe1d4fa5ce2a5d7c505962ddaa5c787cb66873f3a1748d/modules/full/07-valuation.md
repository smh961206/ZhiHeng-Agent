# 7. VALUATION ENGINE：估值方法选择与计算协议

## 7.1 先选模型，再算价格

根据商业模式自动匹配。

### 稳定消费 / 成熟龙头
- PE
- DCF
- FCF Yield

### 高成长公司
- DCF
- Forward PE
- PS + 盈利路径
- PEG 仅辅助

### 银行
- PB
- ROE
- 股息率
- 股利折现

### 保险
- P/EV
- ROE
- 新业务价值趋势
- 分红能力

### 公用事业
- DCF
- 股利折现
- 股息率

### 周期股
- PB
- 中周期盈利
- EV/EBITDA
- 资产价值

### 资源股
- 商品价格周期
- 成本曲线
- 储量
- Capex
- FCF
- EV/EBITDA / NAV（适用时）

### 科技平台
- 收入增长
- 利润率
- FCF
- 用户/ARPU
- DCF
- PE / FCF

### 多元化集团
- 优先考虑 SOTP

## 7.2 至少两种方法

深度研究原则上使用至少两种方法交叉验证。

若行业特性导致只能可靠使用一种：
必须解释原因。

## 7.3 DCF 计算协议

### Step 1：选择现金流口径
- FCFF → 企业价值
- FCFE → 股权价值

不得混用。

### Step 2：建立基准现金流
使用正常化口径，不机械使用周期高点。

### Step 3：预测显性期
通常 5–10 年，取决于：
- 行业成熟度
- 竞争优势持续期
- 可预测性

预测必须解释：
- 收入增长
- 利润率
- 税率
- Capex
- 营运资金
- 现金转化

### Step 4：折现率

FCFF：WACC。

```text
WACC = E/(D+E) × Ke + D/(D+E) × Kd × (1-T)
```

Ke 可使用：

```text
Ke = Rf + Beta × Equity Risk Premium
```

如存在显著国家风险，可单独说明。

禁止为了得到想要的目标价任意调低折现率。

### Step 5：终值

优先选择：
- 永续增长法
- 退出倍数法（辅助校验）

永续增长率必须符合长期经济常识；不得长期高于合理名义经济增长假设而不解释。

### Step 6：EV → Equity Bridge

若使用 FCFF：

```text
Equity Value
= Enterprise Value
- Interest-bearing Debt
- Minority Interest（如适用）
+ Cash / Excess Cash
+ Non-operating Investments（如适用）
```

租赁负债、养老金等项目必须与 EV 口径保持一致。

### Step 7：每股价值

```text
Per Share Value = Equity Value ÷ Diluted Share Count
```

优先使用稀释后股本；ADS/H股/A股必须处理换算关系。

## 7.4 相对估值协议

比较前统一：
- 财报期间
- 盈利口径
- 一次性项目
- 净现金/净债务
- 增长水平
- 会计差异

至少分析：
- 当前估值
- 3年历史分位
- 5年历史分位
- 更长周期（数据可得时）
- 同行业
- 同类优质公司

历史低估 ≠ 当前必然便宜。

## 7.5 三情景估值

至少建立：

| 参数 | 悲观 | 基准 | 乐观 |
|---|---:|---:|---:|
| 收入增速 | | | |
| 利润/FCF增速 | | | |
| 长期利润率 | | | |
| ROE/ROIC | | | |
| 折现率 | | | |
| 终值假设 | | | |
| 合理价值 | | | |

输出：
- 悲观价值
- 基准价值
- 乐观价值

禁止只给一个目标价。

## 7.6 敏感性分析

至少测试：
- 增长率
- 折现率

若参数仅变化 1–2 个百分点就使估值大幅变化：
【估值敏感度高】。

对应动作：
- 扩大估值区间
- 提高所需安全边际
- 降低研究置信度

## 7.7 收益率锚与主估值冲突

若股息收益率锚与 DCF / PE / PB / 资产价值明显冲突：
必须解释冲突来自：
- 盈利周期
- 支付率
- Capex
- 增长性
- 杠杆
- 利率 / 风险溢价
- 一次性分红

禁止选择对自己结论更有利的一种而忽略冲突。
