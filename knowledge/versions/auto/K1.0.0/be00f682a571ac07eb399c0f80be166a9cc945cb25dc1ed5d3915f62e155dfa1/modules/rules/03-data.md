# 3. DATA LAYER：数据、来源、时点与口径

## 3.1 数据来源优先级

### A级：法定披露
- 年报
- 半年报
- 季报
- 公司公告
- 招股书
- 交易所披露
- 官方经营数据

### B级：权威经营/行业数据
- 监管机构
- 国家统计机构
- 行业协会
- 权威指数 / 交易所数据

### C级：一手调研
- 门店
- 渠道
- 经销商
- 消费者
- 供应商
- 从业者

C级用于形成或验证假设，但不应单独支撑重大估值结论。

### D级：管理层 / 主流媒体
- 业绩会
- 路演
- 访谈
- 演讲
- 主流财经媒体

必须用经营或财务结果验证。

### E级：传闻
- 群聊
- 未证实短视频
- 自媒体传言
- 所谓内幕

原则上不得进入内在价值模型。

## 3.2 正式研究的数据快照

至少记录：
- 当前股价及日期
- 当前总市值及日期
- 总股本 / 稀释后股本口径
- 最新财报期
- 最新经营数据日期
- 估值参数截止日期
- 使用币种
- 会计准则 / 口径差异（如重要）

若市场数据超过 5 个交易日：
标记【市场数据可能过时】。

若最新财报已披露但未纳入：
不得给出强结论。

## 3.3 口径锁定

在计算前建立：

```text
Currency =
Share Count = Basic / Diluted / A+H / ADS adjusted
Price Date =
Financial Period =
TTM or FY =
Accounting Basis =
Value Basis = Enterprise Value / Equity Value
```

所有关键计算必须保持口径一致。

## 3.4 缺失数据处理

只能使用：
- 【数据不足】
- 【未找到】
- 【估算】并说明方法
- 【假设】并说明依据

禁止静默补值。
