# 5. FINANCIAL ENGINE：财务验证系统

## 5.1 核心原则

财务分析不是罗列指标，而是回答：

1. 数字为什么会这样？
2. 数字是否与业务逻辑一致？
3. 利润是否能转化为现金？
4. 增长是否需要越来越多资本才能维持？

## 5.2 资产负债表顺序

```text
现金
→ 应收
→ 存货
→ 固定资产 / 在建工程
→ 商誉 / 无形资产
→ 经营性负债
→ 有息负债
```

### 现金
- 现金规模
- 短债覆盖
- 受限资金
- 是否依赖融资

### 应收
比较：
**应收增速 vs 营收增速**。

若长期更快，调查：
- 信用政策
- 客户质量
- 账龄
- 坏账
- 主营收现

### 存货
跟踪：
- 存货 / 营收
- 周转天数
- 减值
- 渠道库存

### 固定资产 / 在建工程
判断：
- 扩产节奏
- 产能利用率
- 折旧压力
- 投资回报

### 商誉
检查：
- 商誉 / 净资产
- 并购历史
- 标的兑现
- 减值风险

### 负债
区分：
- 融资性负债
- 经营性负债

不得简单认为负债越低越好。

## 5.3 利润表与现金流

至少分析：
- 营收
- 毛利 / 毛利率
- 销售费用
- 管理费用
- 研发费用
- 财务费用
- 净利润
- OCF
- Capex
- FCF / FCFE / FCFF（按适用口径）

趋势优先：
- 5年
- 最近 8 个季度（数据可得时）

## 5.4 利润质量四问

1. 收入是真的吗？看主营收现 + 应收。
2. 毛利是真的吗？看毛利趋势 + 同业。
3. 费用有效吗？看销售/研发投入是否换来收入、份额、新品或竞争力。
4. 利润变现金了吗？比较净利润与 OCF / FCF。

## 5.5 ROE

使用杜邦：

```text
ROE = 净利率 × 资产周转率 × 权益乘数
```

判断高 ROE 来自：
- 高利润率
- 高周转
- 高杠杆

若主要依赖高杠杆，降低质量评价。

## 5.6 ROIC 标准口径

非金融企业优先使用：

```text
NOPAT = EBIT × (1 - 有效税率)
Invested Capital ≈ 有息债务 + 股东权益 - 非经营性现金及等价物
ROIC = NOPAT ÷ 平均 Invested Capital
```

必要时对以下项目做一致性调整：
- 商誉
- 经营租赁
- 非经营性投资
- 一次性项目（包括重组）

若无法可靠计算：
标记【ROIC口径不足】，不要给虚假精确值。

银行、保险等金融企业不机械使用工业企业 ROIC。

## 5.7 FCF 口径分层

### Quick FCF
适用于非金融企业快速筛选：

```text
Quick FCF = OCF - 资本开支
```

仅作为快速代理，不自动等于可分配给股东的现金。

### FCFF
适用于企业价值 DCF：

```text
FCFF = EBIT × (1-T)
     + D&A
     - Capex
     - ΔNWC
```

### FCFE
适用于股权价值分析：

```text
FCFE ≈ OCF - Capex + 净新增借款
```

按公司实际口径进一步调整。

### 金融企业
银行/保险不得机械使用 OCF-Capex 作为核心自由现金流。
优先使用：
- PB / ROE
- 股利折现
- 可分配资本 / 偿付能力
- 适合时的 FCFE

## 5.8 正常化利润 / 正常化现金流

估值前必须检查：
- 一次性收益/损失
- 资产处置
- 补贴
- 大额减值
- 周期高低点
- 会计政策变化
- 并购摊销

优先级：
1. 经济逻辑明确的正常化口径
2. 最近 3 年滚动平均
3. 最近完整年度（稳定型公司）
4. 中周期盈利（周期股）
5. Forward 正常化口径（必须有充分证据）

## 5.9 财务红旗

重点检查：
1. 应收长期增速高于收入
2. 存货/营收持续抬升
3. 固定资产/在建工程高速扩张
4. 短债集中但现金不足
5. 高商誉 + 高频并购
6. 净利润增长但 OCF 持续落后
7. 高增长依赖信用扩张
8. 战略与资本投入不匹配
9. 毛利率异常偏离同业
10. 大额关联交易
11. 频繁变更会计政策
12. 非经常性损益长期支撑利润

红旗不是自动淘汰，但必须解释。
