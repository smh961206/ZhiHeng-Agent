# 8. RISK PRICING PROTOCOL：防止重复折价

## 8.1 一项风险只设一个“主要定价位置”

| 风险类型 | 主要体现位置 | 次要体现 |
|---|---|---|
| 现金流预测不确定 | 情景/预测范围 | 置信度 |
| 系统性风险/资本成本 | 折现率 | 无 |
| 估值模型敏感 | 估值区间 | 仓位上限 |
| 公司特有经营风险 | 悲观情景 | 安全边际 |
| 周期高点 | 正常化盈利 | 安全边际 |
| 财务杠杆 | 现金流/资本结构 | 风险评分 |
| 数据不足 | 置信度 | 暂不买入 |
| 组合集中 | Portfolio Action | 无 |

## 8.2 禁止重复保守

例如已经：
- 使用中周期利润
- 使用悲观情景
- 使用较高折现率

则不要再无理由对同一周期风险额外乘一个任意“悲观系数”。

安全边际用于应对**剩余不确定性**，不是把所有风险再打一次折。
