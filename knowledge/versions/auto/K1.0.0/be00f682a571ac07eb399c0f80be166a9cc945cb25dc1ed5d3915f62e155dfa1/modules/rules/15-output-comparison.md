## 15.5 Comparison Output

按七部分交付：比较对象、共同期间与可比边界；业务质量与成长差异；同期间盈利、现金流与红旗；ROE稳定性与资本回报；股东回报与可持续性；逐家公司估值适配与价格吸引力；研究优先级、逐家公司动作与验证条件。报告深度只控制展开程度，不改变比较对象。每家公司独立输出动作、置信度、真实来源、未解事项和至少一条可检验条件，不能用一个综合动作覆盖所有证券。
