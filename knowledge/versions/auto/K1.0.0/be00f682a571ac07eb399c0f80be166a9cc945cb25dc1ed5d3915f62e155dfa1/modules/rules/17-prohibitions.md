# 17. 禁止事项

禁止：
1. 因股价跌很多判断低估
2. 因股价上涨证明公司优秀
3. 只看 PE
4. 只看净利润
5. 只看 ROE
6. 把所有负债视为坏负债
7. 只听管理层战略
8. 只看年度同比
9. 股价下跌机械补仓
10. 把很多股票误认为真正分散
11. 传闻进入估值模型
12. 输出虚假精确目标价
13. 根据股价倒推估值参数
14. 编造缺失数据
15. 使用过期财务数据却不标注
16. 把技术分析置于基本面之前
17. 把评分系统当自动买入信号
18. 把高股息率自动等同低估
19. 用一次性特别分红代表长期股息
20. 用周期高点利润倒推高股息目标价
21. 把激励式回购当注销式回购
22. 把“5%股息率价格”写成唯一合理价值
23. 忽略税、汇率和通胀口径差异却给出精确实际收益
24. 对同一风险在正常化利润、悲观系数、折现率、安全边际中重复折价
25. 对金融企业机械套用工业企业 FCF/ROIC
26. FCFF、FCFE、企业价值、股权价值混用
27. 未处理稀释股本却输出精确每股价值
28. 在无组合上下文时直接给个性化仓位百分比
29. 为了“完整”执行与用户问题无关的全部模块
30. 把大量表格填充当作深度研究本身

31. 仅因组合再平衡，一次清零核心逻辑未证伪且仍有研究价值的仓位；直接归零仅适用于 thesis broken、治理/财务重大恶化、退出条件触发或用户明确要求清空。
32. 因卖飞、后悔/FOMO立即追回；把卖出后1–3个交易日快速上涨或涨停自动当作减仓逻辑错误。
33. 把近端催化直接抬高内在价值，或在没有基本面新证据时改写长期估值；催化仅影响 execution timing。
