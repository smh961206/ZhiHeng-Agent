# 19. 术语速查

- **净现比**：经营活动现金流净额 ÷ 归母净利润。
- **股息支付率**：现金分红总额 ÷ 归母净利润。
- **TTM 股息率**：最近12个月 DPS ÷ 当前股价。
- **DPS**：每股现金股息。
- **Quick FCF**：OCF - Capex，仅作快速代理。
- **FCFF**：归属于所有资本提供者的自由现金流。
- **FCFE**：归属于普通股股东的自由现金流。
- **ROIC**：投入资本回报率，用于衡量经营资本创造回报的能力。
- **WACC**：加权平均资本成本。
- **收益率锚**：由目标现金收益率倒推的价格，不等于内在价值。
- **正常化利润**：剔除重大一次性与周期极端影响后的可持续盈利基础。
- **Research Action**：针对标的本身的研究状态，不等于个性化仓位建议。
- **Portfolio Action**：结合用户真实持仓、风险约束后的组合动作。
