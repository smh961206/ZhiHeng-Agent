# V4.3 版本说明

发布日期：2026-09-08。文件版本：V4.3.0；运行元数据：`4.3-core` / `4.3`。

- [CORE 完整文件](V4.3.0_CORE_SKILL.md)
- [FULL 完整文件](V4.3.0_FULL_SKILL.md)
- [来源与 SHA-256 校验清单](manifest.json)

本版直接基于 V4.2 完整版本，撤除 V4.0→V4.1 引入的增强内容，继续继承 V4.1.1 与 V4.2 的独立改进；不是将项目整体回退到 V4.0。

| 范围 | V4.3 处理 |
| --- | --- |
| 市赚率三公式与修正式 | 移除计算协议、支付率修正系数及经验阈值 |
| 市赚率配套模块 | 移除数据契约、ROE专属输入模块、支付率专属输入模块、价格锚、判断看板、评分联动、变更记录、输出要求、专项审计与术语 |
| 股票池增强 | 移除行业龙头锚与预设数量的阶段筛选链 |
| V4.0 基础框架 | 保留六类任务、基本面、行业、财务、股东回报、PE/PB等相对估值、DCF/DDM、正常化现金流、股息收益率锚、三情景、安全边际与基础审计 |
| V4.1.1 执行改进 | 保留公开验证计划、真实工具记录、年度/累计/单季口径、参考材料边界、财报更新基线、多公司独立取证与分类报告要求；移除其对退休模块的引用 |
| V4.2 执行纪律 | 保留研究判断与组合操作分离、分批减仓、观察仓及退出条件、近端事件、重新买入和四层交易复盘，以及10项执行审计与3项禁止事项 |

ROE、PE、PB和股利支付率仍是基础财务或估值指标。此次移除的是把它们组合成市赚率及其衍生模型的规则，不删除正常化盈利、分红可持续性或常规同行比较。

## 项目同步

1. `knowledge/CORE.md`、`knowledge/FULL.md` 及框架版本同步到 V4.3。
2. 新研究的模型提示、公开计划、报告章节、计算入口和复核约束同步调整；市赚率计算实现与模型工具入口移除。
3. 研究手册删除6个相关术语，保留13个基础术语；首页与研究标准说明同步调整。
4. 旧版本原件与历史报告保留，历史工具名称仍可显示。旧框架的中断任务重试时改按新规则重新研究，并明确提示版本变化；同版本任务继续断点恢复。
5. 已在更新前后执行自动备份。本目录是发布快照，后续修改应保存为新的版本或自动快照。

变更摘要中的退休规则名称仅用于说明版本差异，不代表它们仍是本版执行要求。章节中保留的“V4.2”标签表示继承规则的来源。
