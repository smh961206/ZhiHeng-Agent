# V4.4 版本说明

发布日期：2026-09-08。发布版本 V4.4.0；运行版本 `4.4` / `4.4-core`。以当前 V4.3.0 为内容基线。

**本次仅做文件拆分与按需加载，不修改任何分析规则、公式、参数、评分、模式范围或交付内容。**

| 更新 | 实际处理 |
| --- | --- |
| 专项独立文件 | CORE/FULL 原文拆为 68 个模块，任务路由和输出模板进一步按模式分文件 |
| 入口精简 | CORE.md / FULL.md 改为导航索引，完整规则位于 modules/core/ 与 modules/full/ |
| 按需读取 | 启动读取目录；研究时按现有模式选取核心模块；详细协议通过规则检索补读；审计阶段加载审计模块 |
| 搜索与缓存 | 标题和正文摘要索引筛选文件，命中后读取原文，返回真实文件路径与行号；已读模块缓存 |
| 完整性与追溯 | 模块逐字拼接可还原 V4.3 两份原文件，SHA-256 与来源记录在清单中；研究保留完整版本指纹 |
| 备份 | 自动快照覆盖入口、目录与全部模块；模块改动后更新索引并重新备份 |

模块中的旧版本标题、历史说明和原有章节编号逐字保留。运行版本由 V4.4 索引、模块目录和研究框架确定。没有用重写正文的方式更新这些标签，确保“不更新内容”可核验。

本目录保存发布时的索引及全部模块。运行时仅读取 knowledge/ 下当前入口和模块，不读取此历史快照。恢复本版本时，将 CORE.md、FULL.md、modules.json 与 modules/ 一起恢复到 knowledge/，并使用配套 V4.4 加载程序；不能只恢复两个入口。

验证包含：V4.3 原文字节完整性、六类模式、快筛读取范围、股息与执行辅助模块、DCF 定向检索、正文关键词检索、缓存、文件校验失败、模块快照及旧任务恢复边界。业务规则相关既有测试继续执行，交付协议版本仍为 7。
