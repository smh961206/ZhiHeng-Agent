# 4. FINANCIAL ENGINE

财务分析不是罗列指标，而是解释：

**数字为什么这样，以及是否与业务逻辑一致。**

## 4.1 资产负债表顺序

```text
现金 → 应收 → 存货 → 固定资产/在建工程 → 商誉 → 经营性负债 → 有息负债
```

重点：
- 现金能否覆盖短债
- 应收增速 vs 营收增速
- 存货/营收与周转
- 扩产与产能利用率
- 商誉减值
- 融资性负债 vs 经营性负债

## 4.2 利润与现金流

至少看：
- 营收
- 毛利率
- 销售/管理/研发费用
- 净利润
- OCF
- Capex
- FCF/FCFE/FCFF（适用口径）

优先：5年 + 最近8季度趋势（数据可得）。

## 4.3 利润质量四问

1. 收入是真的吗？主营收现 + 应收。
2. 毛利是真的吗？毛利率趋势 + 同业。
3. 费用有效吗？费用投入是否换来增长/份额/竞争力。
4. 利润变现金了吗？净利润 vs OCF/FCF。

## 4.4 ROE

```text
ROE = 净利率 × 资产周转 × 权益乘数
```

若高 ROE 主要来自高杠杆：降低质量评价。

## 4.5 ROIC

非金融企业优先：

```text
NOPAT = EBIT × (1-T)
Invested Capital ≈ Interest-bearing Debt + Equity - Non-operating Cash
ROIC = NOPAT ÷ Average Invested Capital
```

必要时一致调整：商誉、经营租赁、非经营性投资、一次性项目。

无法可靠计算：标记【ROIC口径不足】。

银行/保险不机械使用工业企业 ROIC。

## 4.6 FCF

### Quick FCF

```text
Quick FCF = OCF - Capex
```

仅作非金融企业快筛代理。

### FCFF

```text
FCFF = EBIT×(1-T) + D&A - Capex - ΔNWC
```

用于企业价值 DCF。

### FCFE

```text
FCFE ≈ OCF - Capex + Net Borrowing
```

用于股权价值分析。

银行/保险不得机械使用 OCF-Capex；优先 PB/ROE、DDM、资本约束或适合的 FCFE。

## 4.7 正常化

估值前检查：
- 一次性损益
- 资产处置
- 补贴
- 大额减值
- 周期高低点
- 会计政策变化
- 并购摊销

优先：
正常化经济口径 > 3年滚动 > 最近完整年度（稳定型） > 中周期盈利（周期股） > 有证据的 Forward。

## 4.8 红旗

重点检查：
1. 应收增速长期高于营收
2. 存货/营收持续上升
3. 固定资产/在建工程高速扩张
4. 短债集中、现金不足
5. 高商誉 + 高频并购
6. 净利润增长但 OCF 落后
7. 高增长依赖信用扩张
8. 战略与资本投入不匹配
9. 毛利率异常偏离同业
10. 大额关联交易
11. 频繁改变会计政策
12. 非经常性损益长期支撑利润

红旗必须解释，不能机械判死刑。
