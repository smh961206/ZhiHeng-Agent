## 9.2 离散评分锚

5分项优先：0 / 1 / 3 / 5；必要时 2 / 4。

不鼓励 3.7、4.3 等伪精确。

评分是 Research Dashboard，不是自动买入信号。

高分 + 高估 = 好公司，坏价格。

## 9.3 研究置信度

输出：高 / 中高 / 中 / 中低 / 低。

依据：
- 数据完整度
- 时效
- 商业模式可理解性
- 会计复杂度
- 估值稳定性
- 关键变量不确定性

数据不足优先降低置信度，不提高估值精度。
