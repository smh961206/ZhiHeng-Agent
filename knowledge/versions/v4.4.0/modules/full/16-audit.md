# 16. AUDIT ENGINE：正式输出前强制检查

## 16.1 Data Audit

- [ ] 当前股价、总市值、股本时点一致
- [ ] 最新财报已纳入
- [ ] 关键定量数据有来源或【数据不足】
- [ ] 币种统一
- [ ] 多公司比较年度和口径一致
- [ ] TTM / FY 未混用

## 16.2 Fundamental Audit

- [ ] 业务、商业模式、战略、财务证据链一致
- [ ] 定价权有证据，不是品牌印象
- [ ] 收入、利润、现金流可以相互解释
- [ ] 应收、存货、Capex、债务红旗已检查

## 16.3 Cash Flow Audit

- [ ] FCF 口径适合该行业
- [ ] 银行/保险未机械使用 OCF-Capex
- [ ] 正常化利润已排除重大一次性项
- [ ] 周期股未使用高点利润直接估值

## 16.4 Shareholder Return Audit

- [ ] 支付率口径未混淆
- [ ] 分红有现金流覆盖分析
- [ ] 回购已区分注销式和激励式
- [ ] 分红承诺已核查
- [ ] 使用滚动数据降低单年噪音
- [ ] 可分配现金与“利润悲观系数”没有重复折价

## 16.5 Valuation Audit

- [ ] 至少两种估值方法，或解释为何只能一种
- [ ] FCFF / FCFE 与 EV / Equity Value 未混用
- [ ] EV→Equity Bridge 完整
- [ ] 使用稀释后股本（如适用）
- [ ] 三情景估值完成
- [ ] 敏感性已检查
- [ ] 收益率锚明确不是内在价值
- [ ] 主估值冲突已解释

## 16.6 Risk Double-count Audit

- [ ] 周期风险是否已在正常化利润体现？
- [ ] 系统性风险是否已在折现率体现？
- [ ] 公司特有风险是否主要在悲观情景/安全边际体现？
- [ ] 是否又额外无理由乘悲观系数？
- [ ] 评分是否重复奖励/惩罚同一因素？

若同一风险被重复定价：修正。

## 16.7 Decision Audit

- [ ] 买入区间来自估值，不是股价走势
- [ ] Research Action 与 Portfolio Action 已分开
- [ ] 未掌握用户组合时没有给伪精确仓位
- [ ] 证伪条件明确
- [ ] 数据截止日期与研究置信度已给出

### V4.2 Execution Audit

涉及减仓、清空、重新买入或交易复盘时执行；不适用项注明原因。

- [ ] Portfolio Reduce / Rebalance ≠ Research Exit；减仓原因与 thesis 状态已分别记录，未因组合再平衡自动下调 Research Action。
- [ ] 组合超配、单股集中、风险因子集中或资金再分配且核心逻辑未证伪、未触发直接归零条件时，默认分2–3档执行，未一次清零。
- [ ] 首档先降到目标区间上沿或显著更可控仓位，已写明后续档位的复评条件。
- [ ] 是否保留最小有意义观察仓已有说明；规模依据账户规模、最小交易单位、流动性和用户约束，未硬编码。
- [ ] 直接归零有 thesis broken、治理/财务重大恶化、退出条件触发或用户明确要求清空的依据；未以单纯再平衡或高估替代退出条件。
- [ ] 当日/立即减仓前已检查未来约5个交易日的财报、分红登记/除息、回购、正式价格政策、行业供需/产量等确定性事件与高相关催化，日期、来源、确定性及缺失项已记录。
- [ ] 催化仅影响 execution timing；若改变长期估值，已记录基本面新证据与参数变更，未直接抬高内在价值，未用催化拖延已触发退出。
- [ ] 卖出后1–3个交易日快速上涨或涨停未被自动判为减仓逻辑错误，未因后悔/FOMO立即追回。
- [ ] 重新买入有新事实支持，且通过原买入条件与组合约束；未以单纯上涨或恢复原持仓为依据。
- [ ] 复盘已区分研究判断错、估值错、目标仓位错、执行过快，并按当时可得证据记录结论与修正动作。
