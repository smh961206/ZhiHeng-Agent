# V4.5 单一规则来源

发布日期：2026-09-08。发布版本 V4.5.0，运行版本 4.5；基于 V4.4。

**本版将 CORE/FULL 双份正文归并为一套专项规则，不增加投资方法、公式、评分权重或研究模式。**

| 调整 | 结果 |
| --- | --- |
| 执行入口 | 统一为 [ENTRY.md](ENTRY.md)，只负责版本和加载，不维护精简正文 |
| 模块目录 | [modules.json](modules.json) 是唯一目录 |
| 专项正文 | 68 个双份模块归并为 35 个唯一模块，位于 modules/rules/ |
| CORE 独有细节 | 12 项约束迁入对应专项，包括接口与股类边界、资本开支精度、亏损比较、价值口径、供应链、ROIC调整、回购核验、折现率、组合风险、矛盾处理、风险评分与模型适配审计 |
| 其他整理 | 版本元数据集中到入口，旧版执行范围说明保留归档；共 14 项可追溯修改 |
| 按需执行 | 六类任务使用同一规则来源，输出按模式选择，审计仅维护一份 |
| 历史追溯 | V4.4 和更早版本完整保留；旧任务沿用现有版本变化检查，不把旧提示续接到新规则 |

[逐项去重记录](deduplication-v45.json)列出每个 CORE 模块的归并目标和 14 项具体编辑。[发布校验清单](manifest.json)记录本目录文件的 SHA-256。

V4.4 仅拆分文件、逐字保留原文；V4.5 执行语义去重和独有约束归并，因此不宣称正文逐字不变。FULL 原有详细规则除清单列明的编辑外均保留，历史更新叙述留在旧版归档，不作为当前业务模块。

恢复本版本时，将 ENTRY.md、modules.json、modules/ 一起放入 knowledge/，并使用配套 V4.5 加载程序。去重记录供追溯，无须加载到模型。后续修改保存到新发布或自动快照，不覆盖此目录。
