# 6. SHAREHOLDER RETURN ENGINE：股东回报与资本配置

## 6.1 基础验证

对有稳定分红或回购记录的公司，至少关注：
- 股息支付率
- TTM 股息率
- 净现比
- FCF / FCFE 对分红覆盖
- 净现金 / 净债务
- 注销式回购收益率
- 股本变化

判断顺序：

**利润 → 现金 → 必要再投资 → 债务 → 分红 → 回购。**

## 6.2 回购分类

| 回购类型 | 典型目的 | 对每股价值影响 |
|---|---|---|
| 注销式回购 | 注销股份 | 直接减少股本，可能增厚每股价值；计入股东现金回报时需看价格与实际注销 |
| 激励/员工持股 | 授予员工 | 通常不能等同现金分红 |
| 库存股 | 资本管理 | 需看后续注销或再发行 |

## 6.3 8 年股息专项

MODE F 默认使用最近 8 个完整年度。

收集：

### 盈利与分红
- 营收
- 归母净利润
- DPS
- 现金分红总额
- 支付率
- 年度股息率

### 现金流
- OCF
- Capex
- FCF / FCFE
- 净现比

### 资产负债
- 现金
- 有息负债
- 净现金 / 净债务
- 资产负债率

### 股东回报
- 注销式回购
- 激励类回购
- 股本变化

## 6.4 分红承诺

核查：
- 公司章程最低现金分红条款
- 未来三年股东回报规划
- 最低/目标支付率
- 有效期
- 触发条件
- 历史兑现率

约束力参考：

**法规/章程 > 正式股东回报规划 > 条件性政策 > 管理层口头表态。**

必须区分：
“现金分红占利润分配总额比例” ≠ “现金分红 ÷ 归母净利润”。

## 6.5 可分配现金优先原则

不默认使用“悲观系数 × 净利润”作为首选。

优先顺序：

1. 可持续 FCFE / 可分配现金
2. 可持续 DPS
3. 正常化利润 × 可验证支付率
4. 数据不足时，才使用利润到可分配现金转换系数

### Earnings-to-Distributable-Cash Conversion Factor

仅在无法直接得到可靠可分配现金时使用。

不得机械固定 0.8。

需要依据：
- 净现比
- 维护性 Capex
- 周期性
- 营运资金
- 债务偿还
- 监管资本要求

若已经直接使用正常化 FCFE，不再额外乘一次“悲观系数”。

## 6.6 收益率锚公式

### DPS 口径

```text
目标收益率价格 = 可持续 DPS ÷ 目标股息率
```

### 正常化利润口径

```text
可持续分红 = 正常化净利润 × 可持续支付率
每股可持续分红 = 可持续分红 ÷ 稀释后股本
目标收益率价格 = 每股可持续分红 ÷ 目标股息率
```

### 可分配现金口径

```text
可持续股东现金回报 = 可持续分红 + 可持续注销式回购
股东现金回报率 = 可持续股东现金回报 ÷ 当前市值
```

收益率锚必须与主估值交叉验证。

## 6.7 3年滚动

至少对以下指标输出“最新年度 + 最近3年滚动”：
- 归母净利润
- OCF / FCFE
- 现金分红
- 支付率
- DPS
- 股息率

目的：降低单年噪音和特别分红误导。

## 6.8 股息敏感性

根据行业测试：
- 可持续现金兑现 / 分红水平
- 目标股息率

典型目标收益率可测试：3% / 4% / 5% / 6% / 7%，但按行业调整。

若参数微调导致价格大幅变化：
【股息估值敏感度高】。

## 6.9 ROIC / WACC 与资本配置

核心问题：

**这 1 元现金留在公司，还是分给股东，长期价值更高？**

若 ROIC 明显高于资本成本且仍有大量高回报再投资机会：
高分红不一定最优。

若 ROIC 接近/低于资本成本、行业成熟、现金流稳定：
提高分红或注销式回购通常更有价值。

## 6.10 股息可持续性评分（0–10）

| 维度 | 分值 |
|---|---:|
| 利润稳定性 | 2 |
| OCF/FCF/FCFE覆盖 | 2 |
| 分红承诺与兑现 | 2 |
| 资产负债表安全 | 1.5 |
| 支付率合理性 | 1 |
| 注销式回购/股本纪律 | 0.5 |
| ROIC与资本配置 | 1 |

解释：
- 9–10：高可持续
- 7–8.9：较高
- 5–6.9：中等
- 3–4.9：偏弱
- <3：不可依赖

该专项分只映射到 100 分体系中的股东回报项，禁止重复计分。
