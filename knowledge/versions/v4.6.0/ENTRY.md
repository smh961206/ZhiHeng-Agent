# 价值投资研究执行入口

业务规则的唯一正文位于 modules/rules/，文件、章节和校验值以 modules.json 为准。

MODE B 按 Quick、Standard、Deep 选择初始加载章节；未加载的详细计算协议通过 read_rules 补读，其他专项保留各自必需流程。执行输出说明与作战图分别触发。

执行当前计划的主模式，读取通用原则、对应路由和所需专项；输出模板按本次交付类型选择。需要详细协议时通过 read_rules 按标题或关键词读取原文。进入复核阶段再读取审计专项。

入口只负责加载，不另写公式、评分或判断条件。模式、辅助模块和输出深度沿用当前计划；详细规则未读取时不得声称已经执行。组合约束、股东回报、执行复盘及作战图按任务触发。

规则有变更时更新目录和校验，重启后端生效。历史版本供追溯，不作为当前规则加载来源。
