# V4.6.0 按研究深度加载

基于 V4.5，仅调整加载行为与文件边界。一个执行入口、一份目录、36 个专项文件；研究公式、评分权重、判断条件、六类任务及第 7 版交付协议不变。

## 加载调整

| 场景 | 初始加载 |
| --- | --- |
| MODE B / Quick | 基本面 4.1、4.3、4.4、4.6、4.7；估值 7.1、7.4、7.7；详细评分按需补读 |
| MODE B / Standard | 完整基本面；估值除 7.3 DCF 详细计算协议外全部加载；详细评分按需补读 |
| MODE B / Deep | 完整基本面、估值计算协议与评分规则 |
| 普通执行或交易复盘 | 独立加载执行输出说明，不连带加载作战图 |
| 用户要求作战图、估值图、买入区间图 | 加载作战图及其评分依赖；涉及执行时再加载执行输出说明 |

MODE B 各深度均保留完整数据、财务、风险计价、决策、置信度、禁止事项与最终原则。省略的细则列入按需补读目录；需要使用时先通过 read_rules 读取原文，再执行。补读不自动扩大任务输出范围。其他模式继续保留各自专项协议，股息专项的八年流程不因深度被裁剪。审计仍在复核阶段加载。

## 原文完整性与维护

原 15-output-battle-map.md 在“V4.2 执行输出联动”标题前拆分，执行部分保存为 15-output-execution.md。按目录顺序拼接这两个文件可逐字节还原 V4.5 原文件；其余 34 个业务文件与 V4.5 逐字节一致。目录记录拆分来源与字节范围。
