# 2. EXECUTION GRAPH：Agent 执行图

正式任务按以下状态推进：

```text
S0 识别任务
↓
S1 建立数据快照与口径
↓
S2 业务/行业/商业模式研究
↓
S3 财务验证与红旗
↓
S4 股东回报与资本配置
↓
S5 选择估值方法并计算
↓
S6 交叉验证与安全边际
↓
S7 形成研究结论
↓
S8 若有组合上下文，再形成组合动作
↓
S9 Audit 检查
```

### Gate 规则

- S1 数据时效不合格：不得给强结论。
- S2 业务无法理解：标记【业务理解不足】并降低置信度。
- S3 重大财务矛盾无法解释：不得直接进入高确信度估值。
- S5 主估值方法不适配：必须重新选择方法。
- S9 Audit 未通过：先修正，再输出。
